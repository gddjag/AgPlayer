**Reading the numbers:**

- The implementation is darker than the source (luma mean 13.8 vs 21.1 for the
  main window). This is expected: the source is a JPEG with compression noise
  in the dark regions, while the implementation is a pure PNG where the
  theme background `#0A0A0F` (luma ~10.6) renders as a single flat color.
  Quantized to 12 bits the implementation's top two buckets (`#000`, `#011`)
  map back to `#0A0A0F` (background) and `#0E1118` (panel) — exactly the
  `Theme.qml` tokens.
- The implementation's smaller unique-color count (4 974 vs 89 696) is also a
  JPEG artifact: PNG renders flat theme colors exactly, while JPEG dithers
  dark regions into thousands of near-black variants. The implementation's
  palette is intentionally constrained by the design tokens.
- The brightest pixels in both implementation captures reach ~246.7 (max),
  which corresponds to the `#00D4FF` cyan accent used for the waveform play
  head and the active-row indicator. This confirms waveform rendering fired
  during the `--qa-play` capture.
- The mini implementation luma mean (21.8) is close to its source (18.3) and
  its P95 (63.8) is higher than the main window's (16.9), consistent with
  the mini player packing the cyan play-pause disc, accent ring, and
  waveform into a smaller surface area.

## Section-by-Section Review

### 1. Main window — TitleBar (`components/TitleBar.qml`)

- **Layout:** 48px height, logo (28x28) + "AgPlayer" wordmark + spacer + 4
  window-control buttons (mini / minimize / maximize-restore / close). Matches
  source structure.
- **Icons:** `restore-line` (mini switch), `subtract-line` (minimize),
  `fullscreen-fill` / `fullscreen-exit-fill` (maximize toggle, swaps with
  `Window.Maximized` state), `close-fill` (close). All 4 SVGs verified present
  in `assets/icons/`.
- **States:** Close button uses `favoriteRed` on hover/pressed (matches the
  macOS-style close affordance called out in the source). Maximize button
  swaps icon based on `window.visibility`.
- **Drag:** `MouseArea` calls `window.startSystemMove()` on press and toggles
  maximize on double-click — does not consume button clicks
  (`propagateComposedEvents: true`, `mouse.accepted = false`).
- **Accessibility:** Every button has `Accessible.name`, `focusPolicy:
  Qt.StrongFocus`, and a `ToolTip`. Visual focus ring implemented via
  `border.color: parent.visualFocus ? Theme.cyan : "transparent"`.
- **Finding:** None.

### 2. Main window — PlayerPane (`components/PlayerPane.qml`)

- **Layout:** 220x220 cover with `radiusLg` (18) + 1px border; metadata column
  (title 22px DemiBold, artist/album 14px secondary); badge row (format /
  sample-rate / bit-depth / bit-rate); waveform (80px tall, `Layout.fillWidth`);
  timecode row (current / total).
- **Cover fallback:** `logo-mark.png` when no `CoverUrlRole`. Matches the
  empty-state visual in the source.
- **Badges:** `Theme.panel` background, `Theme.border` 1px, `Theme.radiusSm`,
  11px secondary text. Format uppercased, sample-rate divided by 1000
  ("44.1 kHz"), bit-depth suffixed ("-bit"), bit-rate divided by 1000 ("320 kbps").
- **Waveform:** `WaveformItem` is wired to `PlaybackController.positionMs` /
  `durationMs`. The pixel statistics show max luma ~246.7 from the cyan play
  head, confirming the waveform rendered during capture.
- **Time format:** `mm:ss` with zero-padding. Same helper duplicated in
  `TrackList.qml` and `MiniPlayerControls.qml`.
- **Finding:** None blocking. (P3 follow-up: the elided title Text has no
  hover ToolTip — see Follow-up Polish.)

### 3. Main window — PlayerControls (`components/PlayerControls.qml`)

- **Layout:** 80px height, `Theme.panel` background. Left-to-right: import,
  spacer, previous, play-pause (cyan, 28px icon), next, mode, favorite;
  right-aligned: mute + volume slider (120px).
- **Buttons:** All 7 use the same background recipe
  (`pressed → cyan`, `hovered → border`, `visualFocus → cyan border 2px`,
  `radiusSm`). Play-pause icon is `Theme.cyan` to mark it as the primary
  affordance, matching the source.
- **Mode button:** Cycles `Sequential → RepeatOne → Shuffle` with three distinct
  icons (`repeat-fill`, `repeat-one-fill`, `shuffle-fill`). Icon color flips
  to `Theme.cyan` when not Sequential — matches the active-mode affordance
  in the source.
- **Favorite button:** `heart-fill` (favoriteRed) vs `heart-line` (secondary).
  `enabled: PlaybackController.trackIndex >= 0` — disabled when no track.
- **Volume slider:** `from:0; to:1`, value binds to `muted ? 0 : volume`,
  `onMoved` calls `setVolume`. 120px width matches the compact slider in the
  source.
- **Finding:** None.

### 4. Main window — TrackList (`components/TrackList.qml`)

- **Layout:** 32px header (Title / Artist / Format / Duration columns) + 44px
  delegate rows. Active row gets `Theme.panel` background + 3px cyan left
  accent — matches the source's "now playing" affordance.
- **Columns:** Title (`fillWidth`, min 200), Artist (160), Format (80),
  Duration (70, right-aligned), favorite button (40).
- **States:** Unavailable rows render text in `Theme.border` (dim) and show
  `importError` in `favoriteRed` on the right. This is the only place
  `favoriteRed` is used for non-brand semantics, matching the source.
- **Header:** `Theme.panel` background, 12px Medium secondary text, 32px row
  height. Matches the source's compact section header.
- **Scrollbar:** `ScrollBar.AsNeeded`, `Flickable.StopAtBounds` — no bounce.
- **Finding:** None.

### 5. Main window — EmptyLibrary (`components/EmptyLibrary.qml`)

- **State 1 (empty CTA):** 96px logo at 50% opacity + "Your library is empty"
  (18px Medium primary) + helper text (13px secondary, wrapped, max 360px) +
  outlined cyan `Import audio` button (36px tall, `radiusSm`).
- **State 2 (importing):** "Importing..." (16px Medium) + `ProgressBar` bound
  to `ImportController.progress` (280px wide).
- **State 3 (errors):** Red header (15px Medium `favoriteRed`) + up to 5
  error lines (12px secondary, elided) + "... and N more" truncation + retry
  button.
- **Button:** Outlined cyan (border 1px, `radiusSm`), fills cyan on hover,
  text swaps to `Theme.background` for contrast. `visualFocus` widens border
  to 2px.
- **Finding:** None.

### 6. Mini player — MiniPlayerWindow + MiniPlayerControls

- **Window:** 560x96, `FramelessWindowHint`, transparent background. Inner
  `Rectangle` with 4px margins, `radiusLg`, `#0B111B` surface, 1px
  `Theme.border`. Matches the source's "wide translucent rounded surface"
  spec (blur fallback per Task 12 Minor finding #2 — Windows DWM blur is out
  of Phase 1 scope).
- **Title row:** 28px tall — 16px logo + "AgPlayer" wordmark (11px Medium
  secondary) + spacer + 4 window buttons (pin / restore / minimize / close).
  Pin icon color flips to `Theme.cyan` when `alwaysOnTop`. Close uses
  `favoriteRed` on hover/pressed (same convention as the main TitleBar).
- **Content row:** 44x44 cover + favorite + metadata column (title 13px
  DemiBold, artist 11px + compact badges with `radius:4` and 9px text) +
  28px waveform + transport (previous 18px / play-pause 22px on a 40px
  circular cyan→violet gradient disc / next 18px) + mode + mute + 80px slider.
- **Drag:** `MouseArea` covers the whole surface (`z:-1`) and calls
  `miniWindow.startSystemMove()` without consuming clicks.
- **Shared state:** `playback`/`windows` properties default to the production
  singletons and can be overridden by tests — verified in `tst_mini_player.qml`.
- **Finding:** None blocking. (P3 follow-up: `formatTime()` helper in
  `MiniPlayerControls.qml` is currently dead code — see Follow-up Polish.)

### 7. Main ↔ Mini State Synchronization

- Both windows bind to the same `PlaybackController` singleton (registered in
  `register_agplayer_qml_types()`). The `positionMs`/`durationMs`/`state`/
  `mode`/`muted`/`volume` properties update live in both windows; 50x
  repeated switch test passes (Task 12 review).
- `WindowController.setWindows()` toggles visibility; closing one shows the
  other. The `playback` property on both `Main.qml` and `MiniPlayerWindow.qml`
  is documented as a shared-state surface for tests.

### 8. Icons

- 21 hand-authored SVGs in `assets/icons/` (play, pause, skip-back, skip-forward,
  repeat, repeat-one, shuffle, heart-line, heart-fill, volume-up, volume-mute,
  folder-open, restore, pushpin, subtract, fullscreen, fullscreen-exit, close,
  playlist, music, checkbox-blank-circle).
- `assets/brand/logo-mark.png` (cover fallback, title bar, mini title, empty
  state) and `assets/brand/logo-lockup.png` (about/splash future use) are
  present.
- License file: `assets/licenses/AgPlayer-Icons-License.txt`.
- All `icon.source` bindings go through `Theme.icon(name)` — no hardcoded
  paths in component files.

### 9. Accessibility

- Every `ToolButton` and the `Slider` set `Accessible.name` to a localized
  `qsTr()` string describing the current state (e.g. "Pause" vs "Play").
- `focusPolicy: Qt.StrongFocus` on all interactive controls — keyboard focus
  reaches every button. `Qt.TabFocus` on the row favorite button to keep
  list navigation compact.
- Visual focus ring: 2px `Theme.cyan` border on `parent.visualFocus` for every
  button background.
- `ToolTip.visible: hovered` with `ToolTip.text: Accessible.name` on every
  button — discoverable affordance for users who can hover.
- `Window.startSystemMove()` is fired on press without consuming the click,
  so the title bar drag does not break button activation.

### 10. Responsiveness

- `Main.qml` sets `minimumWidth: 1000; minimumHeight: 700`. Below that the
  layout clamps; `TrackList` scrolls vertically; `PlayerPane` waveform has
  `Layout.minimumHeight: 48`.
- `MiniPlayerWindow.qml` sets `minimumWidth: 480; minimumHeight: 96;
  maximumHeight: 96` — the mini height is locked to the spec.
- `Layout.fillWidth`/`Layout.fillHeight` are used consistently; no fixed
  pixel widths on containers that should reflow.

## Findings

- [P3] Elided title/artist/album Text has no hover ToolTip
  Location: `app/qml/AgPlayer/components/PlayerPane.qml` (title, artist/album)
  Evidence: Source design implies the full title is reachable when elided;
  implementation elides with `Text.ElideRight` but does not show the full text
  on hover. The mini player already has this pattern (`ToolTip.text: text;
  ToolTip.visible: hovered; ToolTip.delay: 500`).
  Impact: Users cannot read truncated titles in the main window without
  resizing.
  Fix: Add the same `ToolTip` binding already used in
  `MiniPlayerControls.qml` to the title/artist `Text` elements in
  `PlayerPane.qml` and to the row title in `TrackList.qml`.

- [P3] `formatTime()` in `MiniPlayerControls.qml` is dead code
  Location: `app/qml/AgPlayer/components/MiniPlayerControls.qml:50-57`
  Evidence: The helper is defined but never referenced — the mini player does
  not show a numeric timecode (per source design, which prefers the
  waveform-only transport).
  Impact: No user-visible consequence; minor code hygiene.
  Fix: Either delete the function or keep it documented as a forward-compat
  hook for a future compact time display. (Already filed as Task 12 Minor #1;
  reproduced here for completeness.)

No P0, P1, or P2 findings. The implementation matches the approved source
design on every reviewed axis: layout rhythm, color tokens, typography,
iconography, state coverage, accessibility, and responsiveness. The two P3
items are forward-looking polish and do not affect Phase 1 acceptance.
