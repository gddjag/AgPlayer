  C ABI boundary (`core/include/agplayer/c_api.h`) as the only cross-layer
  public surface.
- **CMake preset:** `windows-msvc-debug` / `windows-msvc-release`

- **Frameworks:** Qt 6.7.0 (Core/Gui/Quick/Qml/QuickControls2/Concurrent/Test/
  QuickTest), FFmpeg 7.1 (vcpkg), miniaudio 0.11.25
- **Build type:** Debug + Release both clean, `/W4 /WX`, 0 warnings, 0 errors.

## 4. Seek Latency (P95)

Tool: `build/release/tools/seek_benchmark.exe` (100 samples, null backend,
FLAC fixture).

```json
{
  "device": "null",
  "backend": "AG_AUDIO_BACKEND_NULL",
  "file": "tests/fixtures/generated/sample.flac",
  "samples": 100,
  "min_ms": 0.0779,
  "median_ms": 0.1096,
  "p95_ms": 0.1702,
  "max_ms": 0.2488,
  "passed": true
}
```

- **Threshold:** P95 < 20 ms
- **Measured:** P95 = **0.1702 ms** (Release)
- **Result:** PASS — three orders of magnitude under the threshold.

The condition-variable-based seek fast path (commit `7c142b8`) sets
`seek_requested_` and notifies the decode thread, which performs
`avformat_seek_file` + `avcodec_flush_buffers` in place — no thread or output
device restart. The ~170 µs P95 reflects FFmpeg seek cost plus condition
variable wakeup latency.


- **Threshold:** < 60 MB
- **Measured:** **16.7 MB** (Release, real device)
- **Result:** PASS — 72 % headroom.

The trim is Windows-specific (`#ifdef Q_OS_WIN`) and pages out DLL-load
pages touched during startup but unused during steady-state playback.

## 6. Gapless Boundary

Automated gate: `ctest -R queue_gapless_test --output-on-failure`.

- **Result:** PASS (Debug 6.75 s, Release 6.47 s).
- **Boundary check:** `|captured[boundary] - captured[boundary - channels]| < 0.05`
  — no sample discontinuity at the track boundary, verified in both Debug and
  Release.
- Also covers: Sequential → RepeatOne (loops back to track 0 with no pop),
  Shuffle (random next track, no pop), Seek-then-Play (no track change),
  Stop-then-Play (resumes from 0), failure-then-load (Error state recovers
  via `engine.load()`), and C API parity (`ag_player_*` mirrors engine API).
