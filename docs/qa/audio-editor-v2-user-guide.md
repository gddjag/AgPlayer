# 音频编辑使用说明

1. 打开“音频工具”，选择“音频编辑”，点击“导入音频”载入 WAV、FLAC、MP3 等已支持格式。该页面不再提供任何录音功能。
2. 在时间线拖动建立选区。选区默认循环播放；单击其他位置可从新位置播放，右键选区可取消框选。
3. 使用“分割”或 `S` 在播放头处分割。分割后的片段可单独选择，并拖动左右边缘做非破坏式裁剪。
4. 使用 Delete 删除选中片段；复制、剪切、粘贴和撤销/重做分别使用 `Ctrl+C / X / V` 与 `Ctrl+Z / Y`。
5. “清除”会移除时间线上的全部片段，但保留当前工程文档；需要时可立即撤销。
6. 鼠标滚轮配合 Ctrl 缩放时间线，Shift+滚轮横向滚动。深度放大时会按可见 PCM 重建细节，处理期间不会先清空旧波形。
7. 波形中央细线是片段音量线。上下拖动调整片段基础音量；双击添加音量控制点，拖动控制点的时间和高度制作淡入、淡出或局部音量变化。
8. Space 播放/暂停；Home 回到开头；左右方向键后退/前进 5 秒；Ctrl+Space 停止。播放区也提供上一段、下一段按钮。
9. 右侧 A–D 检查器依次提供速度/BPM、升调降调、保持音调/Formant 保护和导出设置。仅在后端真实支持且时间线状态有效时启用相关操作。
10. 点击“导出音频”；输出目录为空时先选择目录，随后执行异步导出。失败会显示原因，不会伪报成功。
11. 1280×720 下检查器可滚动；880×560 下点击“编辑设置”展开检查器，播放入口始终保留。
