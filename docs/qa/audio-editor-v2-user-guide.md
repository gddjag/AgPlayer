# 音频编辑使用说明

1. 打开“音频工具”，首项即“音频编辑”；点击“打开”或把音频拖入窗口。
2. 在主波形拖动建立选区；双击清除选区。使用工具栏完成剪切、复制、粘贴、删除、裁剪、静音和淡入淡出。
3. “更多”提供增益、峰值归一化、插入静音、添加/跳转标记和导出选区。
4. 底部可播放/暂停、停止、循环选区和跳转前后标记；缩略条用于快速定位和缩放。
5. 右侧“速度与音高”可检测 BPM、设置目标 BPM、速度、保持音调及音高；试听确认后点击“应用处理”。
6. 右侧“录音”选择设备、声道、采样率、监听和新建/插入模式，再选择 WAV 保存位置。录音可暂停、继续、停止或取消。
7. “保存”写回当前文档；“导出”可另存 WAV、FLAC、MP3、M4A 或 OGG。长任务可取消，失败不会覆盖原文件。
8. 未保存时打开另一文件、关闭窗口或新建录音会先要求确认；异常录音 Journal 会在下次启动时尝试恢复。
