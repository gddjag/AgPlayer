## 同输入对比结论

原生实现与参考图已放入同一张 2169×1131 对比输入检查，而不是只检查单张实现截图。

| 维度 | 结论 |
|---|---|
| 构图 | 低机位、中央高峰、外圈衰减和左侧面板比例与目标一致 |
| 地形密度 | 高密度实例化体素覆盖中央与外圈，明显高于早期版本；达到视频的“连续地形”感 |
| 音乐响应 | 中心亮度、体素高度、彩色冲击波、漂浮体/流星均由现有频谱或节拍特征驱动 |
| 色彩 | 青蓝、珊瑚、粉红、暖白形成稳定逐曲调色板；手动色块也会真实覆盖渲染参数 |
| 镜头 | 拖动、滚轮、自动旋转、节拍冲击及 4 秒恢复均接入相机状态 |
| 波形 | 使用播放器原 `WaveformItem`，透明无边框；合成频谱截图无曲目数据时不伪造波形，真实音频截图有证据 |
| 歌词 | 支持显示开关、左/中/右、水平/垂直、大小、清晰度、纵深和透明度，均写入实际布局/变换 |
| 面板 | 六预设 3×2、歌词与动态参数、颜色选择器、质量/宿主控制均可操作 |

## 可见差异与裁定

- 参考 HTML/视频仍具有更强的多通道 Bloom、发白光带和大范围空气雾化；原生版本的泛光更克制。
- 当前差异是轻量单通道 QRhi 方案的明确边界，不属于控件空壳或数据未连接。若继续追求参考的强泛光，需要评估额外离屏通道、模糊采样、显存和低端 GPU 成本后再做。
- 动态视觉按结构、节奏和感知一致性验收，不声称与某一静态帧逐像素一致。
