# 共享列表、标签与并行模型配置修复

基线：main `0f23817`。范围为本轮三项人工反馈，不改沉浸视觉或播放核心，不更新桌面安装包。

## 实现

- 共享列表：单窗口/专业宿主原来缺少菜单操作信号连接。常驻 LibraryNavigationActions 接通新建、重命名、删除、导入和导出；新建后展开并定位歌单。资源导航清除旧歌单/收藏分类筛选，避免交叉筛选表现为无反应。导入目标与可替换的主题宿主分离，原生文件选择器按需创建。
- 标签：鼠标点击焦点不再显示白色内环；保留键盘焦点。统一24px高度、10px圆角，名称与数量保持清晰。
- 分离结果：切模型保留已发布的路径、波形、音量及可试听/导出状态，不受新模型支持的声部限制；再次开始分离才清理旧结果。
- 模型配置：每模型独立下载器、队列、取消代次和状态。Python/CUDA/DirectML共享环境各只有一个任务，模型文件下载可并行，界面按taskId独立暂停、继续、取消；共享环境另行显示。已验证配置幂等复用。
- 完整性：目标下载/安装锁防止重复写；已校验的下载缓存复用；旧后台校验只能提交与当前文件指纹相符的结果，不能覆盖新安装状态。未知模型架构仍显示诊断，不把安装Python当作适配成功。
