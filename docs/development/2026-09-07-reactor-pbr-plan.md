## 任务与接口

1. 倒角网格：新增独立 mesh 头与 CPU 几何测试，44 三角形闭合实体。顶点兼容现有 Vertex；通过顶点标记在 vertex shader 中按最终柱宽/高生成等宽倒角。普通粒子保留旧 cube。主代理集成 vertex、GPU 缓冲与 draw。
2. 材质：替换非水墨 terrain fragment 光照，GGX/Smith/Schlick、程序化灯箱反射、厚度吸收和有界内部发光；移除旧伪倒角和顶面亮度下限。保留所有有效控制与顶面局部闪光。主代理提供 worldPosition 与共享阴影接口。
3. 共享阴影：单张方向光深度图，固定世界空间投影；复用同一 deformation vertex shader，独立 shadow UBO。只画 terrain，只衰减外部照明；低质量关闭，不支持采样时安全降级。资源随 renderer 销毁，隐藏不增加帧。
4. 验证：先几何、shader 编译、原生单柱与小阵列，再完整地形、生命周期、现有控制及 GPU 帧率。最终 Diff Review 与真实截图，不将编译/单测当作视觉达标。

## 预检与状态

| 接口 | 协作边界与检查 |
|---|---|
| 网格 → vertex | mesh 头由几何任务负责，vertex 由主代理负责；明确编码与逆缩放，避免长柱倒角拉伸 |
| vertex → fragment | 主代理追加 worldPosition varying；材质任务仅改 fragment，阴影采样由主代理集成 |
| shader → UBO/fixture | 主代理统一布局与两个 renderer 的绑定，避免尺寸或绑定不一致 |
| 材质 → 验证 | 不保留旧高光阈值作为审美结论；保留可解释的过曝、动态反馈和几何证据 |
| 阴影 → 性能 | 增加一遍 terrain draw 和深度图；记录实际帧时间与降级行为 |
