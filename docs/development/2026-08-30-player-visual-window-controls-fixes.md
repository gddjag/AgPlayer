# AgPlayer 播放器视觉、窗口与控制栏修复设计

日期：2026-08-30
状态：已实施并通过完整验证

## 目标与边界

本轮只修复用户列出的十项回归，不重做播放器信息架构。共享业务行为继续由 C++ 控制器提供，双窗口、集成单窗口和迷你播放器只负责各自布局；主题差异继续通过 `Theme` 令牌和共享图标入口同步。

## 统一设计

1. **波形渲染**：在 `WaveformItem` 的公共几何生成层消除首列边界伪影，不能用覆盖矩形吃掉已播放进度。频彩模式改为同一时间轴、同一中心轴上的 Mix/低/中/高四层镜像几何，按透明度叠加混色。
2. **窗口状态**：经典双窗口与集成单窗口分别持久化尺寸；切回经典模式且没有有效经典尺寸时恢复 960×298，而不是继承 1672×941。Windows 任务栏点击走主窗口原生最小化/还原语义，并同步停靠列表窗口。
3. **媒体数据**：封面 URL 在模型入口统一校验。缓存文件失效时重新提取或回退品牌封面；各播放器不再各自判断一个可能已失效的 URL。音频详情弹层放到不受列表裁剪的 Overlay 上。
4. **共享控制栏**：`ExperienceActions` 变为按窗口显隐的共享组件。所有播放器移除外壳切换入口；迷你播放器额外隐藏沉浸入口、保留歌词。沉浸与歌词使用用户提供的 SVG 资产，通过主题着色。
5. **设置与 EQ**：新安装/重置时柱状频谱默认 RGB，单色默认紫色；不覆盖已有用户选择。18 段 EQ 缩小默认与最小尺寸，不降低文字字号，较窄时沿用水平滚动。

3. 运行目标测试、全量构建与测试、QML 静态检查、Windows 原生测试。
