# 播放器与分离修复验收记录

基线为 main `792b732`。本轮按用户七项反馈修复、整合提交并打包；不合入尚未验收的无损准确度试验，也不恢复取消的曲库管理功能。

## 范围与验收

1. 新配置默认经典双窗口，加入歌曲后自动展开歌曲列表，默认容纳十行歌曲。
2. 滚动主题不产生额外独立列表；与单窗口同宽并复用列表。
3. 复验并纳入已有频彩同轮廓修复：普通、RGB与频彩使用相同高度/线条，只有颜色不同。
4. 滚动视口降低波形高度，默认降低视觉滚动速度，中心时间采用分:秒:百分秒；拖动定位行为保留。
5. 滚动头部四层信息与封面垂直居中、均匀排列。
6. 分离页 GPU 自动探测、音轨波形、标准模型推理、一键外置环境配置和下载故障切换逐项验证。大型运行时不内置基础包。
7. 单窗口/滚动同宽及默认十行；最终组合构建、回归和部署启动后才发布。

## 实现与定向证据

- 独立列表生命周期与显示防线均限制为经典模式；曲目数量增加时自动展开。恢复单窗口/滚动时不创建独立列表，也不读取旧滚动独立列表几何。新配置主题保持经典，升级保留用户明确主题与窗口设置。
- 默认经典列表高度 592；单窗口 1386×832、滚动 1386×972；两共享列表均为 x=233、width=856、height=516（36 表头+10×48 行）。小屏按可用屏幕约束，既有用户调整尺寸不强制覆盖。
- 滚动默认和缩放重置改为 8 拍，相比旧 4 拍在同宽/BPM 下视觉移动速度减半；不改变音频速度。波形上下留 16px、降低振幅；四行信息整体与封面居中，中心时间为分:秒:百分秒。
- WaveformItem 统一 mix 轮廓及 2 顶点实线。`build/player-fixes-contour.log` 的真实 D3D11 图像验证：全曲/放大视口各 2320 列比较，轮廓与像素占用差异均为 0；4 个 QA 用例通过。素材为合成音频，不冒充用户歌曲实测。
- 新默认/列表与滚动布局有 RED→GREEN 证据。窗口控制器 57 通过、9 跳过（原生窗口管理器及第二显示器条件），三个 QML 目标和主题生命周期冒烟通过。最终几何同步后两项 QML 再次通过。
- 深浅主题×经典/单窗口/滚动/列表共 8 个最终截图启动检查通过：`build/qa/player-fixes-final-geometry/results.csv`。主代理已对照截图检查 10 行、列对齐及头部/视口布局。
- 分离实际安装、CPU 五轨和 Python 两轨证据见同目录 `2026-09-06-vocal-separation-reliability.md`。保留大型环境外置；未适配模型显示具体原因，不伪装成可运行。
