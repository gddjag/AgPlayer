# macOS 与 Windows 音频改动对齐

日期：2026-09-23。目标分支：`codex/macos-sync-20260920`。

本次将 Windows 分支 `codex/pc-six-track-editor` 的三项改动移入共享 Qt/C++ 实现：

- 柱状频谱：按逻辑窗口宽度排布 4 像素柱体，剩余宽度平均分配到柱间及两侧；保留 1 像素目标间隔和高分屏物理像素描画。对应 `d8278550`，替代此前仅把上限从 128 调到 192 的未提交方案。
- 伴奏分离：五轨卡片使用单文件 HTDemucs FP16；一次推理输出四轨，伴奏由其余声部合成；复用已验证模型的探测会话。保留 macOS 既有紧凑布局及 Intel／Apple Silicon 设备验证逻辑。对应 `a7a8343a`。
- 无损鉴别：在压缩痕迹不充分时分别复核立体声声道，并在结果中记录证据声道；算法与参数版本更新以使旧缓存失效。对应 `d58b18e7`。

本地 Windows MSVC 增量构建通过。频谱窄／常规／宽窗口与非整齐宽度测试在 DPR 1 和模拟 DPR 2 下通过，主窗口及迷你播放器的频谱 QML 检查通过；无损 MDCT 与降采样 MDCT、分离安装／控制器／DSP／原生后端／运行时／输出事务／Worker、分离页面及 macOS 帮助链接测试通过。`separation_real_model_test` 未提供可选模型和音频输入，执行时跳过真模型推理；分离页面的两项可选 CUDA 保留文件测试亦跳过。

此环境未运行 macOS 原生编译、Intel／Apple Silicon 真机推理或实际听音；Windows 分支的真模型记录保留在各自的功能文档中，不能当作本次 macOS 实测。
