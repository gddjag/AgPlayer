# AgPlayer 播放器运行时修复设计与验收计划

## 目标

本轮以 2026-09-03 用户确认的 18 项反馈为合同，在不复制播放核心、波形缓存、列表数据模型或主题状态的前提下，修复经典双窗口、集成单窗口、滚动主题、迷你播放器、音频编辑、伴奏分离、歌词和元数据写入。

## 统一设计

- 经典模式每次从其他主题返回时恢复 `863x266`，三个主题仍使用独立布局；单窗口和滚动模式复用同一套列表列宽与行布局参数。
- 普通播放器波形统一使用同一播放进度对比度下限，右边缘由原生波形坐标映射覆盖到容器最后一个可绘制像素；滚动模式只改变可见时间窗，不拉伸源采样。
- 封面、标题、艺术家/专辑/标签、元数据使用共享垂直居中规则；各主题只决定摆放位置，不复制元数据逻辑。
- 视频拖放复用现有隐藏视频解码与 `VideoPlaybackController`，音频导入逻辑不接收视频文件。
- 歌词继续采用可取消、可超时、逐线路诊断的 provider chain；新增线路必须免费、无需密钥，并保留本地/缓存优先。
- 自定义分离模型检测递归扫描配置根目录。只有当前原生后端真实兼容的模型标记为可用；不兼容的 `.th`/`.pth` 会显示明确原因，不冒充可运行。
- 元数据写入保持备份、原子替换和音频流验证；“强制”表示在安全的容器重封装后再次验证，不跳过验证或伪报成功。

## 测试先行批次

1. 窗口、播放器与列表：经典模式尺寸、迷你主题按钮移除、中文提示、右键信息入口移除、共享列表列宽、封面信息居中、图标尺寸和窄窗不丢控件。
2. 波形与滚动：尾部覆盖、深色进度对比、8 拍视口、中心线拖放跳转、概览进度/悬浮时间对齐。
3. 视频与歌词：视频拖放路由、provider 失败切换、用户可见线路诊断。
4. 音频工具：标题栏、EQ 尺寸、编辑器控件删减、左裁剪回零、右键双击取消选择。
5. 分离与元数据：任意深度模型检测、格式兼容状态、自动设备选择、超时可取消、波形恢复、强制重封装写入。

## 完成门槛

- 每个缺陷先有失败测试或可重复的视觉/运行时复现，再修改生产代码。
- 目标测试、Release 构建、QML lint、完整 CTest 全部通过。
- 运行深色/浅色、经典 `863x266`、窄窗、单窗口、滚动窗口、迷你播放器并截图检查；播放、拖放、波形跳转和工具预览做真实交互冒烟。
- 最终执行 `git diff --check` 和完整 diff review；未验证项必须明确报告。
