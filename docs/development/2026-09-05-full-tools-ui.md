## 全页问题、决定与实施

### 工具窗口与五页导航

**问题：** 标题栏三枚窗口按钮只有 24px，低于 Theme 的 28px 最小交互尺寸；
五个固定 150px 页签在窄窗口缺少收缩策略；未保存确认框未使用主题对话框。

**决定与实施：** 窗口按钮统一使用 `Theme.navigationActionExtent`，同步修正拖拽区
避让；确认框改用 `ThemedDialog`。导航在 960px 以下等分可用宽度，缩小图标和
内边距，页面顺序、文字、图标与入口保持不变。

**验证清单：**

- [x] 三枚窗口按钮使用 28px 共享交互尺寸并保留原操作。
- [x] 五页导航在窄宽度仍按原顺序全部可见。
- [x] 标题、对话框正文使用主字体和 Theme 字号。
- [x] 最终构建后已复拍深浅主题及 880×560 窄窗口，五页入口均可见。

### 音频编辑

**问题：** 13 个命令按钮按比例压缩时，文字与 24px 图标会在中小窗口互相覆盖；
状态栏三段长文本会争抢宽度；检查器局部仍有非标准 34px 控件和散落间距。

**决定与实施：** 命令栏宽度低于 1000px 时等分按钮并切换为 16px 图标模式，
完整名称和快捷键继续由可访问名称与 Tooltip 提供；宽布局保留参考图的文字按钮
和比例。状态栏按优先级省略：始终保留主状态，700px 以下隐藏选区说明，1050px
以下隐藏采样技术信息。检查器输入和按钮统一为 32px Theme 控件高度，间距改用
Theme。舍弃确认框改用主题对话框。

`EditorSlider.qml` 和 `EditorWaveformCanvas.qml` 已检查：滑轨、手柄、命中区已使用
Theme 尺寸，波形轨道的 1px 线、24px 剪辑带和包络点属于编辑语义尺寸，本轮保留。

**验证清单：**

- [x] 宽布局保留 13 个命令的参考宽度与文字。
- [x] 1280px、880px 具备不溢出的紧凑方案。
- [x] 所有命令功能、快捷键、Tooltip 和可访问名称保留。
- [x] 状态栏长文可省略，核心状态不会被技术信息顶出。
- [x] 最终暗亮实图确认命令图标居中、选中态清晰，完整 QML 测试文件通过。

### 格式转换、设置、预检与错误框

**问题：** 原紧凑模式隐藏“从播放列表添加 / 移除选中 / 清空列表”三个入口；
底栏按桌面固定宽度排列，在 1000–1400px 会溢出；表头和任务行高度未对齐
Theme；预检、错误框使用原生对话框和原生文本控件，深浅主题不一致。

**决定与实施：** 1500px 以下启用紧凑方案，五个工具栏入口全部保留并收窄；
底栏压缩进度、并发、结果摘要和按钮，同时隐藏纯装饰图标与分隔线，文字和筛选
功能保留。工具栏/底栏分别收至 56px/64px，表头 36px、任务行 40px。
设置区标题、间距和圆角统一 Theme；预检与错误框改用 `ThemedDialog`，错误详情
使用 180px 可滚动、可选择的主题 TextArea，宽度随窗口收缩。真实 QML 宿主发现
`ColumnLayout` 的换行内容会让 Dialog 隐式高度形成循环，因此改为纯 `Column`，
子项显式绑定内容宽度；确认、取消、复制、关闭统一放在右侧同排底栏。

**验证清单：**

- [x] 添加文件、添加文件夹、播放列表、移除、清空五个入口始终存在。
- [x] 880/1000/1280px 使用紧凑布局，1672px 保留完整设置面板。
- [x] 并发、成功/失败筛选、开始、取消均在底栏范围内。
- [x] 预检继续保留取消/确认流程，错误详情可选择和滚动。
- [x] 真实组件验证确认/取消各触发一次，复制不关闭也不 reject，关闭只 reject 一次。
- [x] 最终增量构建后暗亮预检/错误框四图通过，真实宿主共 4/4 测试通过且无 QML 警告。

### 元数据编辑

`ThemedTabButton` 和现有图标，列表层级统一为 40/36/48/40px。三个对话框改为
主题对话框并补齐主字体、正文大小、换行和响应式宽度。紧凑页签由显式索引管理，
默认打开文件列表，可切换至编辑页再切回；容器固定在 36px，避免页签按钮填满剩余高度。

**验证清单：**

- [x] 紧凑布局仍可在两个面板间切换。
- [x] 三态编辑、状态过滤、预检分支和错误信息未减少。
- [x] 表头与媒体行对齐 Theme 的 36px/48px 层级。

### 文件名处理

**问题：** 工作区本身已有水平滚动保护，但命令栏和摘要底栏过高；三个摘要卡、

字形，字体变化时会错位；列表行高不统一。

**决定与实施：** 1500px 以下使用紧凑底栏，压缩三个摘要卡和按钮并隐藏次要说明，
成功/冲突/撤销信息与开始/取消功能均保留；命令栏 56px，底栏 112/124px，
表头 36px、行 40px。升降、状态和文件标记改用现有主题图标，覆盖确认框改用
主题对话框。

**验证清单：**

- [x] 所有规则、冲突策略、预览、应用、取消和撤销入口保留。
- [x] 880/1000/1280px 的摘要卡与操作按钮有明确不溢出约束。
- [x] 过窄工作区继续通过内部水平滚动访问完整规则。
- [x] 状态不再依赖字体中的勾号、警告和箭头字形。
