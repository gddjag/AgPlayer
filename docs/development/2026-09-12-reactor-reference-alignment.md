# 沉浸反应堆参考对齐与验证（2026-09-12）

参考：[sonic-topography 固定版本](https://github.com/yin-yizhen/sonic-topography/tree/ec8ecbaec0c9c5094b6b1480df0d6b2d32d6349b)。保留现有原生 QRhi、音频核心及导入路径，没有新增运行时依赖。本次没有提交、打包或发布。

## 变更范围

- 沉浸窗口支持文件 URL 拖入，复用现有导入并播放路径，同时注册 Windows 原生拖放。
- 参考默认值恢复：顶起高度 50、亮度 100、波纹宽度/衰减 100、灵敏度 100、转盘速度 0.15 rad/s；参考 EQ、浮动方块、密度沿用原版。迁移仅一次，之后保留用户修改；歌词首次启动关闭。
- 标准预设隐藏无作用的旧材质/重复设置；取消额外中心照明叠加，保留原版材质。参考转盘旋转不再误用摄像机自动旋转。
- 高频流星使用原版 159–174 频谱桶及独立冷却，不再每 8 拍触发。鼓点顶起与彩色冲击波共享确认事件，不再由两个独立门限相互漏掉；移除参考冲击波的旧长间隔门控。
- 点击地面通过相机射线触发冲击波；拖动仍控制视角。
- 新增原生曲面 3D 歌词，纹理仅在歌词/颜色改变时上传，平滑切换并适配明暗主题。它是三行原生实现，并非原版逐字 karaoke 的像素级复刻。

## 原实现不足与专项修补

原显示频谱的平滑和 -30 dB 上限会削弱连续鼓点差分；历史均值门限会把前面的强鼓点或低音尾音当成背景。现在复用同一次 FFT，取未平滑、保留余量的低频检测值，排除 DC 相位泄漏；用攻击增量的 median/MAD 估计噪声，并要求新的上升至下降峰值，避免衰减尾音重复触发。仍保留 120 ms 防重复窗口，因此不能宣称任意密集打击都逐个触发。

## 验证证据

- Release 主程序和受影响测试目标构建成功；最终 CTest 6/6：visual_kick_response、audio_visual_feature_controller、player_experience_controller、terrain_reactor_item、native_drop_router、qml_immersive_integration。
- 实际 PCM→FFT→检测链路：弱/中/强鼓点、持续 110 Hz 低音叠加、44.1/48/96 kHz、快慢间隔均通过。逐间隔断言：5 分钟 1200/1200，60 分钟 14400/14400，快速连拍 120/120，慢速 40/40；持续低音无周期性误触发。不是仅比较总数。
- QML 沉浸拖入测试经过真实导入器并开始播放；原生拖放路由单测通过。没有把 QML 测试等同于人工 Explorer 拖放验收。
- 定向 GPU 回归 10 项通过，覆盖原生歌词、真实 PCM 渲染节奏、波纹控制、静音几何和中心白色面积；旧材质专项测试另有 21 项通过。视觉截图在 build/release/tests/immersive-native-lyrics.png。
- 本地真实文件只读整曲解码诊断：3876.52 s / 232590 分析窗；241.2 s / 14471 窗；331.651 s / 19898 窗；399.107 s / 23946 窗。全部处理到尾部（最后分析窗距解码尾部不足 0.05 s），顶起与波纹事件一致且包络有限。五段触发数分别为 3740/3963/3819/3898/4208、287/275/265/276/278、301/321/312/342/307、385/389/393/390/354。
- 真实曲目没有人工鼓点标签；触发数包含算法识别的低频瞬态，不能据此证明鼓点准确率或各曲风最佳效果。未进行人工听音验收。

## 性能测量

同一机器、Release，64 个预生成 PCM 窗，5 轮各 20000 次，隔离频谱计算：优化前中位 20.5593 μs/窗，优化后 18.7278 μs/窗（约 -8.9%）。两次显示频谱与实际使用检测桶的校验和均为 151647840。仅跳过 505 个未使用检测桶的对数运算，完整显示频谱不变。这不是全应用 CPU、GPU 或帧率指标。

复现入口：visual_kick_response_test --benchmark；可选 visual_music_probe <本地音频路径> 目标为 EXCLUDE_FROM_ALL，不随软件安装。运行诊断需将 build/release/app 加入 PATH。

## 尚不能宣称的结果

“任何音乐绝不漏拍”“全部视觉像素级一致”均未获证明。快慢和长时合成回归只能证明所覆盖条件；真实复杂混音仍需要标注鼓点的逐点比对及用户听音确认。3D 歌词逐字高亮也不在本次已完成能力内。
