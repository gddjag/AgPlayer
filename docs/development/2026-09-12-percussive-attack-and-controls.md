# 鼓点瞬态确认与控制项核验

## 本次范围

用户确认将旋律起伏与强鼓点顶起分开。保留原生 QRhi、现有 FFT、播放核心和依赖；没有提交、打包或发布。

旧版的对数频谱变化会把持续低音和弦的相位干涉当成攻击，并赋予固定鼓点冲量。复现用例：无鼓和弦在 19 秒观察区间触发 108 次，单个持续正弦的旧测试不能覆盖这个问题。

新增 `PercussiveAttack` 在同次 FFT 的线性低频幅度上判断短促增长：与近期幅度分布比较，排除近静音微变和长时间渐强；短暂保留证据供原有峰值确认使用。没有按 BPM 定时制造鼓点。未获瞬态确认时仅保留上限 0.11 的原有轻微呼吸包络；彩色冲击波仍与确认后的强顶起共享事件。暂停、换曲、重置清空独立判定状态。

## 验证

- 7 类无鼓 PCM（高音和弦、低音颤音、慢速渐强、近静音、持续低音和弦、安静和弦、柔和旋律）观察段全部 0 强顶起；峰值包络不超过 0.041。
- 既有真实 PCM→FFT 正例保留：5 分钟 1200/1200、60 分钟 14400/14400、快速连拍 120/120、慢速 40/40，逐间隔检查且覆盖 44.1/48/96 kHz。
- 最终相关 CPU/界面 CTest 4/4 通过；最后的 EQ 控件改动后界面测试再次通过。
- GPU 定向测试 28 项通过、0 跳过，覆盖浮动四控制项、材质亮度/光影、波纹三控制项、原生歌词与真实 PCM 渲染。五个歌词滑条改变画面的像素数分别为 3758、3513、2746、2235、1630，验证的不是仅保存属性。
- Release 主程序及相关目标构建成功。GPU 首次手动启动使用了不正确的运行时搜索路径，未进入测试；结束该自建进程后按 CTest 的 Qt/vcpkg 路径运行成功。

## 人工反馈后的第二轮：原版主检测器与顶起/光色对齐

上面的记录对应 19:25 人工测试包，不代表本轮结果。该包的严格攻击门槛会过滤真实混音中的相同鼓点。

### 本轮修改

- 主检测器恢复参考提交 `ec8ecbaec0c9c5094b6b1480df0d6b2d32d6349b` 的 smoothed-flux mean/std、峰值判定与 120 ms 冷却。包络改用原版显示频谱，而非补充检测用的未平滑频谱；保持原版 floor、breath、attack/release 数学公式。
- 严格线性幅度门槛只用于补充瞬态恢复；恢复候选延迟 80 ms 等待主检测器，主检测成功则取消，补充事件不能重置原版冷却。
- 整段混音的 RMS 渐强不能否决低频鼓点。短起音资格只过滤低频占比超过 95% 的近独立低音长音；不把 BPM/拍数作为触发来源。RMS 在既有 PCM 遍历中计算，重置时清零。
- 原版音色锐度是亮度正差乘 10，可超过 1；去掉参考材质侧面光衰减对锐度的上限截断。回归检查先明确失败，再修正通过。
- 核对 13 个内置预设数据、默认 minimal-monochrome、背景/雾色、45 度 FOV 和默认相机位置对应参数；相符的项目不重写。保留现有原版高度百分比映射（50% 为 1 倍）和原生 QRhi。
- 顶起颜色保持原版的音色冷暖混合、柱高、亮度与预设发光系数；普通波纹覆盖预设 Ripple 色，白色波纹独立叠加。标准预设不启用自定义凝胶补光。包络/高度恢复也会改变这条高度相关颜色路径的实际输出。

### 验证及边界

- 增加独立数值断言：原版 mean/std 门槛、包络高度、恢复不能抢占下一原版事件、被过滤事件不能在尾巴重触发、reset 保留模式；另加整段混音渐强的逐事件回归。
- 相关 CPU CTest 7/7 通过；最后算法整理后重跑受影响的 3 项通过。Release 主程序构建通过。
- 7 类无鼓合成输入观察段仍为 0 强顶起，峰值包络不超过 0.065；5 分钟 1200/1200、60 分钟 14400/14400、快速 120/120、慢速 40/40 等既有逐间隔断言通过。原版算法在构造的柔和低音句上会产生 31 次触发，本轮过滤为 0；这不等于原版对所有无鼓音乐都正确。
- 提供歌曲均只读解码至末尾：Bad Habits 307.714 s / 18462 窗，原版检测事件 472/472 同帧保留；BLACK WINDOW 253.531 s / 15211 窗，311/311 同帧保留。比较是同频谱下原版算法的 C++ 移植，不是浏览器音频端到端采集，也不是人工标注的鼓点召回率。
- 本版包含补充恢复事件：两首总触发数分别为 580 与 369，原版为 472 与 311。额外事件是否全部符合听感，尚须人工同曲确认，不能把“未丢原版事件”解释为无误触发或普遍零漏拍。
- GPU 定向检查覆盖真实 PCM 渲染、稳定相机、浅色曝光、鼓点亮起回落、普通波纹、白色冲击波与静音几何；日志位于 `build/release/tests/reference-realignment-gpu.txt`。最终光感回归日志为 `reference-realignment-final-gpu.txt`。
