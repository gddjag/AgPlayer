## 五项性能处理

1. 缓存统计/自动清理改为低优先级单 worker；200 ms 合并通知，最多一个运行任务和一个后续任务。100 次连续保存通知只启动一次扫描；切换目录/销毁时取消，工作线程不捕获控制器裸指针。
2. 列表批量重排一次构造前缀、所选项、后缀，保留原有排序/模型通知语义。基准受工作站负载影响明显，未证明稳定墙钟提速，不报告百分比。
3. 移除生产没有消费者的 reactor PCM batch 复制和对应死代码；保留生产单帧分析入口及原版逐帧对齐断言，不改已验收的预设、内光、颜色、顶起和冲击波参数。
4. 有序歌词定位改用二分查找，维持边界语义。10 万行尾部查询微基准中位数约 0.25 ms → 0.000015 ms；仅是查找内核，不代表整机或普通歌曲性能倍数。
5. 编辑播放输出和变速输入缓冲保留容量。预热后 512 次实际读取，常速 C++ 分配 512 → 0，0.75 倍速 768 → 0，44.1 kHz 单声道/48 kHz 双声道均经 3 组重复；未测得解码线程 CPU 或整机耗电降幅。
