# 歌词、窗口与交互修复（2026-09-13）

本轮基于 `codex/macos-universal` 的现有工作区修复，保留其他任务已完成但未提交的改动。版本仍为 1.0.3；本轮不提交、不打包、不发布。

## 范围与实现

- 普通歌词阅读区使用独立深/浅色文字色：当前行紫色、上下文灰色不再叠加整体和逐行透明度。当前行继续加粗；沉浸空间歌词的透明度设置保持有效。
- “刷新歌词”请求 LrcAPI 的真实候选列表，检查曲名/艺术家/时长，绕开刷新缓存并排除当前歌曲已明确刷掉的线上歌词内容。生产只配置 HisAtri/LrcApi；不覆盖手动导入的歌词缓存。无合格新候选时明确无匹配，不保证外部服务总有正确歌词。
- 快速搜索统一按当前经典/单窗口/专业模式激活正确窗口并聚焦搜索框，保留默认及自定义快捷键。
- macOS 备用模型说明加入已有 Windows 百度网盘地址和提取码；补充对应英文翻译。
- 首次歌词默认关闭；后续记住歌词、沉浸承载方式、两种内嵌侧栏的页签和展开状态。沉浸正常窗口位置/尺寸持久化，全屏或桌面承载尺寸不会覆盖正常几何；不自动开始播放或重开临时弹窗。
- 右键菜单按真实文字、子菜单箭头、勾选标记和必要边距计算宽度。文字型确认/帮助/错误框按内容、标题、按钮计算并限制在宿主边界内。输入表单、颜色面板、校准操作等保留必要的功能布局宽度，未机械缩成一行文字的宽度。
- 缓存按钮显示真实完成结果、清理数量/空间、空缓存或失败；异步处理中禁重复点击。“全部缓存”保留确认并增加完成反馈。转码独占暂存文件由各任务自动管理，不扫描或清理用户目录，不恢复无实际用途的临时缓存按钮。
- 专业模式控制区取消换行，缩窄时整条控件同步缩放，保留点击坐标映射。经典双窗口搜索筛选区增加 8 DIP 底部留白。
- 默认窗口宽/高各限制在可用工作区约 78%，按系统逻辑坐标处理缩放、任务栏和 Dock，不按硬件英寸猜测。大屏保留舒适尺寸上限；合理手动窗口大小/位置保留，过大或精确匹配旧居中默认的窗口重新适配。经典上下双窗口按组合占用计算。
- 音频工具窗口、设置、均衡器、沉浸窗口同步适配默认/最小尺寸。专业布局按实际剩余高度分配列表；共享筛选栏整体适度缩放，保留搜索、评分、BPM、清空及点击映射。短列表空提示改为表头以下居中，不再错误叠加滚动偏移。
- 格式转换取消小窗强制关闭右侧设置，保留手动收起/展开；格式按钮和状态筛选按宽度换行，并发数字完整显示。标签编辑的应用/取消固定在底部；文件名规则在窄窗复用页签和局部纵向滚动；无损检测短面板为列表保留空间。音频剪辑、人声分离复用已有紧凑布局。
- 设置内容随可用宽度适配并保留纵向滚动，保存/取消固定可见。均衡器的 18 段及前级全部容纳，不依靠横向滚动；紧凑控制区缩放，标题栏保持原生操作尺寸。迷你播放器可缩到 480×160，播放内容等比适配，标题栏保持正常大小。长表单/列表仍在窗口内部滚动，不把所有内容压成无法阅读的一屏。

- Windows 上执行共享 C++/QML 测试。offscreen 测试加载系统字体以使用真实中文文字度量；这不是物理 Mac/Cocoa 或真实多显示器热插拔验收。
- 恢复测试覆盖设置与窗口实例重建，不冒充完整应用进程退出/重启人工验收。
- 原生 Windows 下一个原有吸附测试存在窗口边框度量差异；采用该目标原定的 offscreen 配置后通过，未改旧断言或吸附逻辑。
- macOS 平台分支通过原属性注入验证；最初同名只读属性遮蔽的夹具不能作为生产问题证据，已纠正并保留真实旧文本基线。
- 辅助窗口测试中的沉浸布局夹具关闭渲染、显式展开面板；不冒充热角激活路径验收。均衡器回归使用其原定 `qml_main_window_test` 真实控制器，误用迷你假控制器的诊断日志不作为生产故障结论。
- 窗口默认比例依赖系统逻辑工作区；没有逐台验证 13–43 英寸硬件。现有正常布局保留可读字体，只有受限内容区适度等比收缩；超长表单或任务列表保留可访问的局部滚动。
- 这不是全项目回归、真实听音或发布验收，没有创建安装包或修改线上版本。
