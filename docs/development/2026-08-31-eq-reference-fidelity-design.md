# 18 段 EQ 参考图复刻与真实功能设计

## 目标

以用户提供的 `1672 × 941` 深色参考图为视觉真值，将现有 EQ 从“17 个频段 + 前级”修正为“18 个固定频段 + 独立前级”，并让参考图中的启用、预设、保存、管理、重置、范围、精度、频响曲线、频段/前级调节和输出电平全部连接真实状态或 PCM 处理。

不打包安装程序，不修改音频编辑器、录音、播放器主界面和无关主题行为。

## 已确认事实

- 参考图的固定频段依次为：20、31.5、50、80、125、200、315、500、800、1.25k、2k、3.15k、5k、8k、10k、12.5k、16k、20k Hz；前级是第 19 个独立控制项。
- 当前实现缺少 10 kHz：只有 17 个固定频段，另加前级后被旧文档称作“十八个控制项”。
- 当前频段、前级、启用、旁路和自动防削波已经进入真实 C API、无锁 DSP program 邮箱与音频回调，不是假控件。
- 当前可见界面缺少参考图中的 ±6/±12/±18 范围、三档精度和真实输出电平；底栏显示的是自动防削波信息。
- 当前 8 个内置预设 ID、中文名称和参数为稳定契约；用户要求预设不变。

## 方案比较与决定

1. **只改 QML 外观**：最快，但仍是 17 段，范围/精度/电平只能造假。拒绝。
2. **扩展现有 EQ 模块**：在现有 C API、`GraphicEqualizerProcessor` 和 `EqualizerController` 接口上最小扩展，沿用已经验证的无锁提交、滤波切换与持久化。采用。
3. **替换为第三方 EQ/限制器**：会增加依赖、包体、实时线程风险和预设听感漂移。当前需求没有必要。拒绝。

## 模块与接口

### 核心 DSP 模块

- `AG_EQUALIZER_BAND_COUNT` 与 `kGraphicEqBandCount` 改为 18。
- 固定频率数组在 8 kHz 与 12.5 kHz 之间插入 10 kHz。
- 支持范围扩展为 `-18.0 ... +18.0 dB`；Q 仍由应用固定为 2.145，过渡仍为 25 ms，不新增公开调节面。
- 保留现有 `prepare_graphic_eq()` 预计算和三槽无锁 program 邮箱；音频回调中不分配内存、不加锁。
- UI/C API 的 `set_equalizer()` 非实时路径先完成 DSP program 准备与邮箱提交，只有邮箱接收成功后才发布新的 EQ settings、revision 和 status；测试专用 one-shot 失败注入只用于证明这条提交路径失败时不会提前发布状态，不进入产品控制面。
- 输出表读取设备实际收到的、已经过 EQ、ReplayGain、主音量和曲目过渡的 sample peak。峰值在现有输出乘法循环内累计；原子状态使用立即上升、约 12 dB/s 释放，不增加第二次 PCM 扫描。
- `ag_equalizer_status` 增加 `output_peak_db`，读取无副作用；停止、设备丢失或 seek 静音时回落到静音值。

### Qt 控制器模块

新增并持久化以下小接口：

- `gainRangeDb`：仅允许 6、12、18，默认 12。
- `precisionMode`：高/中/低三档，分别表示 0.1/0.5/1.0 dB 的后续编辑步长。
- `gainStepDb`：供 QML 滑杆、滚轮和键盘统一读取。
- `outputPeakDb`：由可见窗口的 30 Hz 状态刷新更新。
- `setGainRangeDb()`：降低范围时一次性夹紧所有超界频段和前级，只提交一个完整 DSP snapshot；只有曲线实际变化时才转为 `custom`。
- `setPrecisionMode()`：不重写已有曲线，只影响后续用户编辑。
- 控制器只在核心提交成功后更新 revision 并记住新的完整 snapshot；后续任一提交失败时，启用、旁路、保护、前级、范围、全部频段和当前预设必须一起恢复到上一次成功 snapshot。

所有频段仍通过一次完整 snapshot 提交，避免逐段更新造成中间态。

### QML 界面模块

- 参考视口严格使用 `1672 × 941`、深色主题、100% DPI；保留 `1180 × 680` 与 `880 × 520` 的可达性布局。
- 标题改为 `18 段图形均衡器`。
- 顶栏匹配参考图：启用、预设、带现有图标库图标的“保存预设 / 管理预设 / 重置”。
- 主图显示 18 个真实频段增益节点，纵轴跟随当前范围；节点按参考图的等频段槽排列，样条穿过控制器的真实 `bandGain`，明确表达“控制包络”而不是伪装成精确声学测量。
- 频段区显示 18 个固定频段和独立前级；滑杆范围与编辑步长来自控制器，不再硬编码 `±12 / 0.1`。
- 底栏显示范围、精度、真实输出电平分段表和 dBFS 数值。
- 旁路与自动防削波保留真实控制器能力，但移入“管理预设”弹层的高级区，避免破坏参考图主表面，也避免旧用户失去入口。
- 中文和英文是本次最终语言范围；英文资源完整覆盖 EQ 窗口新增的 16 个界面字符串，不依赖旧泰语/越南语目录补位。

## 预设与迁移

### 内置预设不变

- 保留 `flat / bass / classical / pop / rock / vocal / edm / jazz` 的 ID、中文显示名、前级和原有 17 个频段参数。
- 新 10 kHz 参数固定为 `0.0 dB`。零增益 peaking filter 不激活，因此旧预设的 DSP program、频响与预留前级余量保持不变；不是通过插值偷偷改变听感。

### 用户设置迁移

- schema 从 2 升为 3，bandCount 从 17 升为 18。
- 17 段实时曲线和自定义预设在 10 kHz 位置插入 `0.0 dB`，保证升级前后的实际 DSP 响应不变。
- 旧 10 段数据先按现有对数插值规则得到原 17 段结果，再插入零增益 10 kHz；直接升级与先升级到 schema 2 再升级到 schema 3 的结果一致。
- 未知或损坏长度不冒充内置预设；沿用现有 `custom` 降级规则。即使数据声明为 schema 3 / 18 段，只要 `bandGains` 缺失、实际长度不是 18，或声明的 bandCount 与实际长度不一致，也必须降级为 `custom`，不能仅凭保存的内置预设 ID 继续显示为内置预设。

## 失败处理

- 非法范围/精度值返回失败或归一到安全默认，不提交 DSP。
- C API 提交失败时控制器恢复上一次成功提交的完整 snapshot，失败尝试不递增 revision，不能让 UI 与实际 DSP 分叉。
- 核心邮箱提交失败时不发布候选 settings/status；测试可通过 one-shot seam 精确触发一次失败并验证下一次正常提交仍可成功。
- 启动时的 schema 迁移持久化与运行时 accepted snapshot 分离：迁移先把原用户曲线等价写成新 schema，即使首次 DSP 提交失败也不回写引擎默认值覆盖用户配置；UI/引擎仍回到 accepted 默认状态，下次启动重试迁移后的原曲线。
- 输出表无有效 PCM 时显示静音，不伪造活动电平。
- 不支持的采样率/声道数保持现有安全旁路；本次不扩大 DSP 格式支持范围。

## 测试与验收

### 自动化

- 核心：18 个频率、10 kHz 正弦响应、±18 边界、无锁切换、输出峰值 attack/release/静音。
- C API/引擎：18 段完整 snapshot，设备输出峰值位于 EQ、ReplayGain、主音量和过渡之后；one-shot 邮箱失败时 settings/status/revision 保持上一次成功值。
- 控制器：8 个预设旧参数不变且 10 kHz 为零、schema 2/旧 10 段迁移、schema 3 缺失或损坏 `bandGains` 降级 `custom`、范围夹紧的原子提交、三档精度、自定义预设持久化、输出表刷新，以及提交失败时完整 snapshot 回滚且 revision 不递增。
- QML：19 个滑杆、参考按钮、范围/精度交互、保存/管理/重置、键盘/滚轮/双击和窄视口可达性。
- 翻译：中文/英文范围内覆盖 EQ 窗口新增的 16 个可见字符串。

### 视觉

- 将参考图与 Release 实际截图统一为 `1672 × 941`、同一深色状态后合成到同一比较图。
- 主要区域边界容差不超过 4 px；频段中心、标签和按钮对齐容差不超过 3 px。
- 字形抗锯齿与平台字体差异单独记录，不允许用 mask 掩盖几何、裁切或功能缺失。
- 所有 P0/P1/P2 可见差异修复后，`design-qa.md` 才能写 `final result: passed`。

## 明确不做

- 不加入第三方 DSP/限制器依赖。
- 不把自动防削波描述成 true-peak limiter。
- 不把截图生成、编译通过或单元测试通过单独当作完整视觉/听觉验收。
- 不打包 EXE/安装程序；真实声卡与主观听音另列为剩余硬件验收。

## 最终实现裁决

- 参考图的曲线与滑杆纵向位置并不严格遵循其显示的 dB 数值。实现保留线性 dB 映射，不为像素相似度伪造增益。
- 主图采用按 band index 等槽的真实设置包络，使 18 个节点与下方 18 个滑杆一一对齐；精确 DSP 传递响应仍由 `EqualizerController::responseCurve()` 和控制器测试覆盖，但不与设置节点混画成两套相互冲突的主视觉。
- 重置按钮采用仓库已有的环形 `restore-line.svg`。该资产比返回箭头更贴近参考图和重置语义，不新增图标文件。
- 1180 × 680 与 880 × 520 保留纵横滚动能力，并在溢出时持续显示滚动条；底栏输出值和前级均可完整滚动到可视区。
- Pass 1 Design QA 的 1 个 P1、3 个 P2，以及 Pass 2 剩余的 1 个 P2 均已关闭；Pass 3 未发现 P0/P1/P2。

最终视觉证据和验证边界见 `design-qa.md` 与 `docs/development/2026-08-31-eq-reference-fidelity-verification.md`。
