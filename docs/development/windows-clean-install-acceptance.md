# Windows 隔离安装验收

只在可丢弃的 Windows 10/11 x64 虚拟机快照中执行，不能在日用电脑的现有 AgPlayer 安装上做卸载测试。主机开发目录启动不算干净安装验收。

先运行只读预检（不会启动安装器、卸载器或删除文件）：

```powershell
./scripts/qa-windows-install-preflight.ps1 -Installer C:/QA/AgPlayer-Setup-1.0.0-x64.exe -ExpectedSha256 <构建记录中的64位SHA256> -DisposableEnvironmentConfirmed
```

`ready` 只表示基本环境门槛通过，不表示软件安装或发布验收通过。记录输出中的安装包 SHA-256、签名状态及系统版本；未签名需单独记录，不能用自签名冒充可信发行签名。

## 每个平台保留截图和结果

预检存在阻碍时退出码为 2；调用方必须检查退出码和 JSON。检查失败不能当作通过。SHA-256 必须来自独立的可信构建记录，不能对手头未知文件临时算一个哈希就称已验证来源。

1. 从干净快照开始，不安装 Qt、Visual Studio、Python 或额外运行时。安装候选包，检查默认路径、桌面快捷方式、软件与 EXE 版本一致。
2. 正常启动并导入真实 MP3：经典双窗口、纯色波形、默认列表高度、播放/暂停/定位和声音正常。测试文件名及人工听音结果必须记录。
3. 勾选文件关联安装后，通过资源管理器打开音频，核对注册、启动及播放。不修改其他用户的默认应用。
4. 创建测试歌单、标签并改一个设置，关闭应用。先记录其值，再安装候选更新包，检查这些数据仍在。只有同版本包时只能记录“重装通过”，不能称跨版本升级通过。内测 1.1.x → 正式 1.0.0 单独验证手动安装。
5. 卸载时选择保留数据，检查程序和快捷方式移除、个人数据保留；重装后确认恢复。回到快照后另测选择删除数据的卸载路径。不能借测试清理宿主机用户目录。
6. 记录 Windows 版本、DPI、安装包哈希、旧/新版本、每步结果和未验证项。未执行步骤不得标通过。

当前环境只完成只读预检脚本测试；没有可用干净虚拟机，因此上述真实安装、升级、卸载尚未执行。
