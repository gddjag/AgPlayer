# AgPlayer 17 项修复、集成提交与发布计划

## 全局约束

- 集成基线为 `codex/recover-complete-release`；执行前后审计全部 AgPlayer 分支和 worktree，只合并已完成且尚未进入基线的提交。
- 排除未完成的人声分离、声音克隆插件。
- 优先最小修改、复用现有架构和依赖；不得用占位实现、假数据或删除错误处理绕过失败。
- 每个功能组必须测试、审查并独立提交；最终工作树干净后才生成 `C:\Users\Administrator\Desktop\AgPlayer-Setup-Latest.exe`。

## Task 1：列表窗口、导航和跨屏对齐

- 去掉列表工作区外围描边；默认宽度恢复到播放器对齐宽度；左栏为 208px，搜索筛选栏为 54px。
- 标签管理栏收紧到 248px，标签胶囊缩小，中间歌曲列表占用全部剩余宽度。
- 删除标签模式的 1284px 强制最小宽度；进入、退出标签管理不得改变窗口宽度。磁吸时由 `WindowController` 唯一控制列表宽度，并始终对齐播放器。
- 只迁移历史错误默认宽度和已识别的标签页异常宽度，不覆盖用户主动调整的独立窗口尺寸。
- 默认高度按标题栏、表头、10 行和 54px 筛选栏动态计算；波形缩略图开启或关闭都恰好显示 10 首，且用户仍可自由调整高度。
- 导航：`我的音乐库` 为可展开一级节点，自定义歌单为二级；`我的收藏`、`标签管理`为独立一级；移除播放历史、最近添加、从未播放入口但保留兼容数据。
- `资源文件夹`为独立分区，上方有分隔线和清晰加减按钮；支持多级目录树；整个资源区域接受外部文件夹拖入。歌曲行不得移动或复制到磁盘资源目录。
- 修正标签管理图标；目录、歌单、标签使用明确的原生线性图标。
- 测试覆盖导航层级、标签页宽度不变、磁吸跨屏、两种缩略图模式的 10 行高度。

## Task 2：播放器布局、列表波形和拖放

- 播放器核心控制组独立居中；音量滑条为不参与居中宽度计算的右侧浮层，展开时控件不移动。
- 列表缩略波形使用宽度自适应峰值包络；每声道使用完整画布像素预算；缓存高密度量化峰值并按实际宽度重采样；普通缩放绘制连续最小/最大包络，高倍率切换抗锯齿采样折线。
- 保留异步读取、可见行请求、单 worker、LRU 和取消机制，避免 10 行同时阻塞。
- 拖动歌曲时将半透明封面、歌名和多选数量的预览放入窗口 Overlay，持续跟随指针且不受列表裁剪或 delegate 回收影响。
- 自定义歌单和标签提供明确悬停接收态，成功后播放轻量装入动画；资源文件夹不接收歌曲。
- 迷你播放器按艺术家、专辑、可选标签、评分、收藏排列；星星和爱心使用原生尺寸并基线对齐。
- 新建空歌单支持格式说明强制单行，最小宽度下收紧字号和间距而不换行。
- 测试覆盖居中控制组、缩略波形密度、拖放预览和迷你播放器元数据。

## Task 3：音频编辑、选区和录音

- `清除`调用 `clearDocument()`；未保存修改沿用现有确认机制。
- 所有工具按钮显示快捷键提示；`Space`始终播放/暂停，仅文本输入和模态输入让出。
- 编辑器播放或录音前发出统一预览启动信号，由应用层停止主播放器。
- 选区建立后默认循环；播放头在选区外时从选区起点开始；右击选区取消，顶部按钮保留。
- 时间线增加播放头时间胶囊、选区时间/时长胶囊、左下角拖出片段胶囊、24px 隐形边缘命中区、缩放指引、独立播放头拖动层、中心音量线以及淡入/淡出控制点。
- 拖出片段需异步渲染临时 WAV，并通过系统文件拖放到桌面、资源管理器或其他应用。
- 修复每声道像素预算；普通缩放绘制连续包络，高倍率进入逐采样折线。
- 录音按钮单击即启动系统默认 WASAPI 输入；33ms 更新时间、红色播放头、实时波形和绿色分段电平；失败显示具体设备、权限或格式错误；停止后成为可播放编辑文档。
- 使用共享紧凑原生控件，强调色为系统蓝。
- 测试覆盖清空确认、选区循环与取消、边缘拖动、胶囊、片段拖放、双淡化、互斥播放、高倍率密度和录音状态。

## Task 4：格式转换、元数据和文件名

- 格式转换删除右侧搜索框和筛选图标。
- 格式切换时从真实编码能力重建码率模式、码率、采样率、采样格式和声道，并重置失效旧值；无损格式隐藏码率；Opus 使用合法 48kHz；AAC/M4A、Vorbis、MP3 只显示真实支持模式。
- 从真实 QML 点击路径验证 MP3、WAV、FLAC、AAC、M4A、OGG、Opus、ALAC，失败行显示底层原始错误。
- 元数据的单个、已选和全部范围共享目标快照；预检、写入、回读和刷新使用同一批目标；逐文件显示真实约束和结果，部分不支持不得导致整批假失败。
- 元数据预览区裁剪并内部滚动，字段、封面和错误文字不得越界。
- 文件名在 `自动序号`右侧增加独立`删除序号`开关，映射到既有首尾序号规则。
- 文件名处理顺序固定为：删除序号、删除前缀、删除后缀、添加前缀、添加后缀、自动编号；预览和事务使用同一规则对象。
- 测试覆盖 QML 转换入口、元数据单文件与批量写入回读、文件名规则与事务一致性。

## Task 5：任务栏、集成 QA 和发布

- PE、QApplication、所有顶层窗口、快捷方式和注册表统一使用 `AgPlayer.Desktop` 与同一 ICO。
- 恢复 Windows 原生任务栏语义：前台点击任务栏按钮时最小化整个播放器/磁吸列表组，再次点击恢复、置顶并恢复磁吸层级。
- 列表、设置和工具窗口不能形成错误的独立任务栏组；主播放器是窗口组入口。
- 跨屏 DPI 下保持原生像素尺寸，不因最小化、恢复、标签切换或跨屏拖动改变宽高。
- 重新审计全部完成任务、分支、worktree 和提交，只合并尚未进入基线的完成提交；继续排除两项未完成插件。
- 运行范围检查、`git diff --check`、聚焦测试、全量 CTest、Release 构建、视觉矩阵和可执行的真实播放/录音验收。
- 安装后再次执行启动、播放、磁吸和工具烟雾测试。
- 生成优化完整安装包，复制为 `C:\Users\Administrator\Desktop\AgPlayer-Setup-Latest.exe`，报告大小、SHA-256、提交号、测试结果及人工验证项。

## Task 6：标签管理瀑布流与毛玻璃胶囊

- 保留标签管理顶部搜索和新增入口；标签内容区改为 `Flickable + Flow` 自适应瀑布流。
- 胶囊按标签文字与数量使用自然宽度并自动换行，不使用固定列宽网格；248px 标签栏中优先维持 2–3 个短标签同排，长标签独占所需空间。
- 胶囊使用主题化半透明底色、1px 高光边框、轻量阴影和清晰圆角，形成低成本毛玻璃效果；不得为每个胶囊引入昂贵的实时背景模糊或新依赖。
- 默认、悬停、选中、键盘焦点和歌曲拖放接收态都有明确但不过亮的视觉差异；选中态使用低饱和系统蓝。
- 深浅主题下文字、数量、图标和边框满足可读对比；窗口缩放、标签增删、长中文/英文、重复筛选和滚动时布局稳定。
- 保留标签新增、选择、右键菜单、重命名、删除、搜索、歌曲投放及成功反馈的既有交互和数据模型。
- QML 行为测试覆盖自然宽度、自动换行、滚动内容高度、深浅主题对比令牌、选中/悬停/拖放状态及既有标签交互回归；同时执行视觉截图验收。
