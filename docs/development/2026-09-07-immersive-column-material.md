# 沉浸柱体内光与宽地面调整

基线：`dcb8aff`，独立分支 `codex/immersive-gel-material-20260907`。不修改主线正在打包的检出，不合并、不制作安装包。

## 本轮范围

- 复用原生实例化渲染、频谱和节拍包络。柱体侧面增加有色内光，顶部更亮、下部吸光，保留面向光源的明暗差；不是整根白色光条。
- 压低常态曝光，只补强较高柱体的顶面，让强拍仍有亮度余量。保留原防过曝与高光下限测试，没有放宽阈值。
- 默认镜头由距离 164 / 俯角 0.62 改为 148 / 0.72（弧度），形成更满的高处斜视地面。
- 九预设减小柱体尺寸、扩大音频起伏覆盖范围；保留用户柱体密度选择及原质量/自动降级上限。未触顶时实例数增加，因此不是零性能成本。
- 预设按钮改为文字高度加 Theme 内边距，3×3 等宽单行标题，详细说明保留悬停提示。
- 新视频 `微信视频2026-09-07_094336_450.mp4`（12.29 秒）提取 2 FPS 连续帧与 6 秒细节帧。重点参考深色外围、圆形渐隐、局部环形高光和有色中心；不从视频推断源码或精确柱体数量。
- 圆形外沿由半径 86% 开始渐隐改为 60%；最后叠加的发光也随环境距离收暗，避免外圈再次显出实心圆盘。

## 第二轮：侧面材质与发光职责

用户确认只继续调整柱体质感。定位到侧面边缘光使用 `max(abs(x),abs(z))`，侧面固定坐标使 rim 恒为1，整张侧面被均匀补光。

- 侧面改用切向坐标定位竖边；肩部平滑法线只影响受光，不增加 mesh/pass。
- 染色内光使用宽截面分布，中间通透、两侧收暗，同时保留上亮下暗。
- 中心节拍光的空间权重由 `0.45+0.55*core` 调整为 `0.18+0.82*core^1.15`，中心最大响应不变，外围不再被统一提亮；高频顶面流光逻辑未修改。
- 保留上一轮密度、质量上限和圆形渐隐，没有继续增加实例数或调整歌词/歌单/波形。
- 同柱侧面横向受光测试 RED 为0，调整后约3.25级亮度差；不是通过放松阈值获得。新增法线有非零固定面分量，开方与幂输入有界；独立只读审查无阻断问题。
- 第二轮 Release 构建通过，完整 GPU 29/29 通过（`material-round-final-gpu.txt`），稳态 P90/P95/P99 为169/178/201，近白为0；霓虹与星河分别短时播放并截图，正常退出。`column-material-comparison.png` 左旧右新，固定合成频谱近景；`round-1.png` 为实际媒体播放画面。没有扩张为全平台/长时稳定性结论。

材质仍是原网格上的受光近似：侧面轮廓并未变成真实倒角，不能描述为实体折射或真实体积灯管。

## 第三轮：已批准的透光柱材质重做

用户反馈：前两轮以及之后的 emission floor / 表面流纹仍像不透明方块，不能算内部发光完成。上述历史测试只验证局部亮度，不是透光质感验收。

### 目标与设计

方柱保留；改为壳反射、内部有色介质、受控外溢光三层视觉。内部沿局部观察射线计算有限光程和吸收，再合成表面反射，而非继续使用 `max(surface, emission)`。用户最新纠正优先：**内部与外壳必须平滑，不保留参考灯图中的流纹**。只有“多源霓虹”使用纵向彩虹，其他预设保留自身柱体配色，水墨保持独立。上亮下暗、窄边缘反射与顶面闪片分开处理，不让柱内光抹去侧面轮廓。

技术边界：Qt 6.7 / QML / C++17 / QRhi；自有着色，不复制受限制源码，不新增音频解码或运行时依赖。单柱内部合成不等于能看穿到后排柱的场景折射；不引入全场景透明排序。继续独立工作树，不自动提交、合并或打包。
