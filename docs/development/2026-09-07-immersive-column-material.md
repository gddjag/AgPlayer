# 沉浸柱体内光与宽地面调整

基线：`dcb8aff`，独立分支 `codex/immersive-gel-material-20260907`。不修改主线正在打包的检出，不合并、不制作安装包。

## 本轮范围

- 复用原生实例化渲染、频谱和节拍包络。柱体侧面增加有色内光，顶部更亮、下部吸光，保留面向光源的明暗差；不是整根白色光条。
- 压低常态曝光，只补强较高柱体的顶面，让强拍仍有亮度余量。保留原防过曝与高光下限测试，没有放宽阈值。
- 默认镜头由距离 164 / 俯角 0.62 改为 148 / 0.72（弧度），形成更满的高处斜视地面。
- 九预设减小柱体尺寸、扩大音频起伏覆盖范围；保留用户柱体密度选择及原质量/自动降级上限。未触顶时实例数增加，因此不是零性能成本。
- 预设按钮改为文字高度加 Theme 内边距，3×3 等宽单行标题，详细说明保留悬停提示。
- 新视频 `微信视频2026-09-07_094336_450.mp4`（12.29 秒）提取 2 FPS 连续帧与 6 秒细节帧。重点参考深色外围、圆形渐隐、局部环形高光和有色中心；不从视频推断源码或精确柱体数量。
- 圆形外沿由半径 86% 开始渐隐改为 60%；最后叠加的发光也随环境距离收暗，避免外圈再次显出实心圆盘。

- 宽地面 GPU 测试 RED：内外圈亮度约 116 / 73；渐隐后约 114 / 28，外圈能在几何截断前退入背景。

## 第二轮：侧面材质与发光职责

用户确认只继续调整柱体质感。定位到侧面边缘光使用 `max(abs(x),abs(z))`，侧面固定坐标使 rim 恒为1，整张侧面被均匀补光。

- 侧面改用切向坐标定位竖边；肩部平滑法线只影响受光，不增加 mesh/pass。
- 染色内光使用宽截面分布，中间通透、两侧收暗，同时保留上亮下暗。
- 中心节拍光的空间权重由 `0.45+0.55*core` 调整为 `0.18+0.82*core^1.15`，中心最大响应不变，外围不再被统一提亮；高频顶面流光逻辑未修改。
- 保留上一轮密度、质量上限和圆形渐隐，没有继续增加实例数或调整歌词/歌单/波形。
- 同柱侧面横向受光测试 RED 为0，调整后约3.25级亮度差；不是通过放松阈值获得。新增法线有非零固定面分量，开方与幂输入有界；独立只读审查无阻断问题。
- 第二轮 Release 构建通过，完整 GPU 29/29 通过（`material-round-final-gpu.txt`），稳态 P90/P95/P99 为169/178/201，近白为0；霓虹与星河分别短时播放并截图，正常退出。`column-material-comparison.png` 左旧右新，固定合成频谱近景；`round-1.png` 为实际媒体播放画面。没有扩张为全平台/长时稳定性结论。

材质仍是原网格上的受光近似：侧面轮廓并未变成真实倒角，不能描述为实体折射或真实体积灯管。

## 前两轮交付边界（历史）

这是轻量着色近似，不是真实体积透射、折射或阴影贴图；没有新增渲染 pass、透明排序系统、第二次音频解码或运行时依赖。没有复制受限制的 HTML/第三方 Shader。

本轮不宣称与参考视频完全一致，未做 Debug、完整 ctest、30 分钟稳定性、其他平台及全部缩放验收；也不能据此宣称此前沉浸窗口消失问题已彻底修复。

## 第三轮：已批准的透光柱材质重做

用户反馈：前两轮以及之后的 emission floor / 表面流纹仍像不透明方块，不能算内部发光完成。上述历史测试只验证局部亮度，不是透光质感验收。

### 目标与设计

方柱保留；改为壳反射、内部有色介质、受控外溢光三层视觉。内部沿局部观察射线计算有限光程和吸收，再合成表面反射，而非继续使用 `max(surface, emission)`。用户最新纠正优先：**内部与外壳必须平滑，不保留参考灯图中的流纹**。只有“多源霓虹”使用纵向彩虹，其他预设保留自身柱体配色，水墨保持独立。上亮下暗、窄边缘反射与顶面闪片分开处理，不让柱内光抹去侧面轮廓。

技术边界：Qt 6.7 / QML / C++17 / QRhi；自有着色，不复制受限制源码，不新增音频解码或运行时依赖。单柱内部合成不等于能看穿到后排柱的场景折射；不引入全场景透明排序。继续独立工作树，不自动提交、合并或打包。

### 实施与验证计划

- [x] 单柱 GPU 夹具：抽取现有 mesh / UniformBlock 数据契约到 `qt/src/terrain_reactor_gpu_data.hpp`，生产与 `tests/qt/terrain_column_material_test.cpp` 共用。真实 qsb 渲染单柱，固定镜头/音频。混合 DPI 下 grabWindow 的 960/640 截图统一回夹具自身 640 渲染坐标；节拍升高柱体后重新按实际柱面相对高度取样，不比较错位的固定区域。
- [x] 内部介质：`terrain_reactor.vert` 传递未归一化视线与柱体三轴尺寸；`terrain_reactor.frag` 计算折入局部盒体的射线、出射距离，以固定三次采样合成平滑光芯与吸收。无随机纹理、无流纹、无远近 LOD 跳变。保留亮度/清晰度/软硬度/流光控制。
- [x] 光控接线：柱内光芯 0–200%（默认100%）、照亮周围 0–200%（默认20%）、照明范围 20–200%（默认100%）。设置持久化，切换预设不覆盖用户光控。沿用快照/UBO 上传；没有新计时器或音频分析。
- [x] 有限环境受光：四组代表光源使用现有频段、节拍和预设颜色；按世界距离及接收面法线衰减，通道贡献有上限。这是无阴影的分组近似，不是每根柱体一个灯，也不声称具备真实遮挡或灯具级物理照明。
- [x] 柔光实现：替换屏幕中央的装饰椭圆，从真实渲染亮部提取、分离卷积；中间纹理最长边不超过512、缩放不超过1/4。最终仅加局部光晕，不遮盖原柱面，单通道增量封顶0.025。隐藏/关闭/水墨不创建效果资源。原生 GPU 行为验收已通过，具体边界见下表。
- [x] 本轮定向回归与实图：单柱、GPU 地形、控制器、受影响 QML、九预设短时播放已执行。完整产品/长时/跨平台验收仍未执行，不把定向通过当参考图匹配。

### 第三轮中间态证据（以下最终验证更新其状态）

- 平滑内光测试先在旧流纹版真实失败（RMS约2.65–3.57），去纹后晶体、果冻、彩虹三个样本内部时间残差均为0。顶部效果开关不应改变内部纹理。
- `column-locate-green.txt`：指定单柱用例5/5通过；相同柱面晶体/果冻的顶边对比15/9级、横向明暗38级；节拍柱芯亮度约57→72、55→70，彩虹约70→94。它们是合成频谱下的采样证据，不代表参考图通透程度已经验收。
- 独立审查发现旧密集地形测试会重选不同柱体，旧节拍固定ROI混入几何升高。已将同柱材质断言迁到隔离夹具，密集场景仅检查色彩、白化与内部边缘；等待最终回归。没有降低原节拍提亮要求。
- `smooth-controller.txt` 22/22、`smooth-qml.txt` 36/36为第三轮中间态结果；默认外溢降到20%和最新顶面闪片后需重跑。软件QML只证明效果生命周期的负向门控，不证明GPU光晕显示。
- `smooth-terrain-gpu.txt` 为27通过/3失败/1跳过，中间态失败来自上述旧同柱定位断言，不能记为最终通过。
- 1080p高质量、11133柱的修改前墙钟吞吐基线约20.28 ms/帧（含帧调度，非GPU时间戳）；修改后测量待补。新增光晕的实际应用代价另需实测，不能用单个地形渲染测试代替。

### 最终定向验证（本轮代码）

旧顶面闪片将 `randomValue<=0.48` 的柱永久排除。新增低/高随机柱的真实GPU用例先取得RED：低值顶面RMS为0，高值约3.80。修改后所有柱都可以按各自相位出现闪片；闪片只占顶面局部，不进入内部介质。最终低/高样本顶面RMS约2.72/4.10，改变像素占顶面有效采样区约11.5%/12.1%，侧面内部RMS均为0。不是每根柱同时闪白。

全地形回归一度发现常态亮度P90=171，超过既有170上限；顶面合成系数由0.90收低到0.88后复验通过，没有放宽曝光阈值。
