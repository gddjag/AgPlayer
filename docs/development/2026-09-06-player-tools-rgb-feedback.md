# 2026-09-06 播放器、工具和 RGB 反馈修复

基线：`main@3605ccf`。用户已授权整合提交并生成 1.1.1 人工测试安装包；既有已提交分支均为 main 祖先，不重复合并。保留其他工作树内容与旧安装包。

## 实现范围

- 首次配置保持纯色波形、关闭进度针；统一紫色进度针。已保存的用户设置不强制覆盖。
- 重复导入复用曲库元数据，避免再次解码已存在曲目；交付批次时再次确认曲目仍存在，不能复活用户在导入期间删除的曲目。
- 自动标签配色扩展为 20 色，优先选择未使用颜色，再选最少使用颜色；持久化后稳定，不重新染色既有/手选标签，不要求不同库的同名标签同色。
- 资源刷新成功提示 5 秒后消失，错误提示不会被成功计时器隐藏。
- 滚动视口默认/重置 32 拍，网格默认关闭，4 拍绿色、8 拍红色强调；校准使用即时播放快照，控件重排、缩短并对齐。
- 滚动波形按源时间固定采样桶平移，避免每帧重新分桶造成颜色/轮廓闪烁。波形几何与颜色处理分离。
- RGB 公共混色保留真实低/中/高频能量；使用连续相对频段对比，绝对能量亮度独立映射。低红、中绿、高蓝；不是乐器分离。不复制或推定 Rekordbox 私有算法，不随机染色。真均衡三带仍可呈白色。
- 无损工具复用公共深浅主题，任务栏只保留删除选中/清除全部并修复默认宽度溢出；并发控件紧凑化。
- 按需时频图改为最大 256×256 保峰聚合，保留瞬态、窄频峰和静音时间位置；固定不透明连续 dB 色阶。分类规则和阈值未改。
- 非平直 EQ 预设成功应用后启用 EQ 并清除旁路；显示实际采样率/DSP 曲线和保护增益，不再使用仅连接滑杆数值的示意曲线。保留防削波和失败回滚。
- 分离配置异步取消/暂停、阶段无进展超时、官方/备用源切换、半成品隔离和阶段日志；不重复安装已验证环境。重试按钮居中；显示 GPU/驱动和缺失运行组件的区别。
- 沉浸控制面板左侧、队列右侧、共享颜色选择器；减少可见调节项，默认柱体尺寸 0.50，降低高度/不透明度，连续能量平滑。扩大地面并修复中心缝、反向 smoothstep 和高光/稳态亮度超限。

- 深浅主题截图只证明对应界面状态；不代替拖动、实时听音、网络安装或长时间渲染验证。
