当前 Release CMakeCache 确认源目录为本仓库，Qt 路径为 `D:/Qt/6.7.0/msvc2019_64`，使用现有 vcpkg FFmpeg 库。当前 `build/installer` 和 `build/package` 不存在；现有 EXE 不能当作安装包基线。实施前应建立不受其他任务持续修改影响的源代码快照及独立构建目录，记录包含的既有修改清单，以同一快照构建功能前后对照包。

已核实的复用与缺口：

- `DecodedAudioBlock` 当前为 `vector<float>`，`decoder.cpp` 输出固定为 `AV_SAMPLE_FMT_FLT`。未经增益/重采样的标准24-bit整数归一化值可被float32精确表示，不能笼统声称所有24-bit样本都会损失精度；明确缺口是32-bit整数、float64以及原始表示/转换路径证据。
- `WaveformAnalyzer` 有两遍流式、取消和进度回调模式；`audio_engine.cpp` 内为512点float FFT，最终播放谱经过单声道下混、平滑，不能直接用作本功能判定。
- 当前Core/Qt实现未发现SACD只读解析或DSD取证路径，现有格式矩阵未覆盖DSD/DST/ISO。FFmpeg提供编解码器不等于应用已具备该格式的完整读取和鉴别能力。
- 测试侧可执行的FFmpeg已在 `D:/ai/ffmpeg-extract/ffmpeg-6.1.1-full_build-shared/bin/ffmpeg.exe` 实测版本6.1.1；它与产品链接库不同，只用于生成并记录夹具，不加入安装包。

## 推荐方向与取舍

采用 Core 分析器 + Qt 批处理模型 + QML 工作台，保持现有播放接口的默认行为。新增功能使用纯 C++17、已有 Qt/FFmpeg，不引入运行时、模型或 DSP 依赖。

需要确认的架构扩展是：在现有解码能力上增加面向分析的原始精度数据读取能力，以及独立的 SACD ISO 只读轨道输入层。普通播放 PCM 不足以证明原始最低有效位或原始 DSD 特征；不能先损失数据，再给出精确位深判断。

替代方案：直接利用播放输出做频谱可以较快接入，但不能满足完整精度与 SACD 要求；独立复制解码器或打包外部鉴别程序会增加维护和体积成本。均不作为推荐实施方案。

本方案不缩减 PCM、DSD/DST、受支持 SACD ISO、批量操作、报告、校准与视觉验收范围。按阶段验证不等于将未完成格式声明为支持。

## 准确度优化增量（1.3 / params-5）

保持原Core/Qt/QML边界和纯C++17运行时。新增的固定预算DSP测量复用FFmpeg FFT；开发实验的Python/NumPy与FFmpeg命令仅存在本地QA中，不作为产品依赖。

- 频谱绘图下限不再截断低电平分析证据；谱平坦度的几何/算术均值使用相同频点集合。
- 采样栅格循环残差必须同时满足多段相位一致性、残差带宽与带外抑制；原生高采样率FIR滤波的静态边缘只作为候选，不能自行确证升频。
- 2048点变换窗与1152点近似帧的MDCT相位测量分开设门槛。固定四个不重叠片段、逐片段选择活动声道；1152点分支额外要求多个片段的帧相位在两个采样内一致。不能把窗口长度当作精确编码器或码率证明。
- 48kHz PCM另检查CELT低重叠帧：恢复预加重、12帧中位数、四个不重叠片段；全频与18kHz以下分别测量稳健峰值、峰宽和相位。依据[RFC 6716 §4.3.7](https://www.rfc-editor.org/rfc/rfc6716.html#section-4.3.7)，不把低频SILK或任意重采样后的Opus视为已经覆盖。
- 宽频带、健康低位与“没有检测出编码痕迹”不能证明原始无损；强噪声可掩盖有损痕迹，需弃权。
- 置信度仍为未校准的工程证据强度。盲测按录音来源分组，当前格式识别不能抬高隐藏来源的召回率；反例误判纳入precision分母。参见独立的来源准确率评估协议。

MDCT帧差分方法依据：[Kim与Rafii，EUSIPCO 2018，第III节](https://eurasip.org/Proceedings/Eusipco/Eusipco2018/papers/1570436395.pdf)。论文的编码格式分类成绩不等于本实现对无损负例的准确率。另据[Koops等，ISMIR 2024](https://arxiv.org/abs/2407.21545)，熟悉编码设置上的高分可能无法泛化到未见参数；本项目因此保留独立来源与参数验证。

## 数据与判定契约

主判定使用需求中的十个稳定枚举：`CredibleLossless`、`SuspectedLossyTranscode`、`SuspectedUpsample`、`SuspectedBitDepthExpansion`、`SuspectedLossyUpsample`、`CredibleNativeDsd`、`SuspectedPcmToDsd`、`Inconclusive`、`AnalysisFailed`、`Cancelled`。

任务状态独立于判定，依次允许 Waiting → Probing → Decoding/Analyzing → Summarizing → Completed；任何可取消阶段可以进入 Cancelling → Cancelled，错误进入 Failed。重试生成新一代任务标识，丢弃旧回调。文档要求的停止按取消当前任务处理，不增加没有检查点恢复能力的假暂停。

结果包含：schema/算法/参数版本、文件身份、源格式和源采样率、解码视图精度、声道布局、轨道区域/编号、判定、0–100 置信度、候选转换链、证据、覆盖范围、警告、耗时与绘图摘要。DSD 原始采样率与 PCM 分析视图采样率分开保存。

证据包含类型、值、单位、参考阈值、支持/反证方向、独立证据族、覆盖时段和解释。QML 只根据稳定枚举和数值显示，翻译文字不参与逻辑判断。已知有损编码属于已知容器/编码事实，不伪装成检测出的历史转码证据。

置信度表示证据支持强度，未经独立语料校准不描述为统计正确率。候选不足时保留未知；绝不输出可恢复原文件、精确编码器版本或完整转换历史的结论。

## 分析证据与保守边界

| 证据族 | 测量 | 必须考虑的反证 |
| --- | --- | --- |
| 带宽 | 跨窗口截止、斜率、分位数、时间/声道稳定性 | 模拟低通、老录音、语音、内容本来缺乏高频；单一截止不能判有损 |
| 编码结构 | 子带空洞、块状周期、瞬态前回声、谱熵/平坦度 | 重复乐器结构、窗函数泄漏、混响；相关指标不得重复计权 |
| 量化 | 原始整数低位占用、步进、重复零位、抖动统计 | 静音、低电平、DSP/增益改写、浮点来源；有效位深不等同 ADC 性能 |
| 重采样 | 候选倍率、滚降、镜像/混叠相关性 | 原生低带宽录音；没有镜像不证明未重采样 |
| DSD | 原始比特/重复模式与解码频谱交叉、超声整形斜率与稳定性 | PCM 转 DSD 也可能具有噪声整形；仅看 DSF/DFF 或噪声不能确认原生 |
| 内容质量 | 活动度、静音、动态、底噪、声道相关/相位、解码完整性 | 极短、截断、NaN/Inf、异常声道必须降级或失败 |

流式全文件活动度与统计扫描，结合有效窗口和可疑区间多分辨率分析。FFT 参数集中命名，Hann 窗、幅值归一化、Nyquist 与频率轴有数值测试。优先抽取现有可复用 FFT；现有 FFmpeg `libavutil/tx.h` 也提供 double FFT，可作为不增加依赖的备选，实施前比较实际复用成本。

阈值须在训练/校准语料上确定，在未见编码参数及内容上单独报告表现。不给尚未测试的阈值伪造“专业级”依据。冲突证据、覆盖不足、低信息量输入回退 `Inconclusive`。

SACD reader 只处理已有且无需破解的镜像，明确区分立体声/多声道区域与轨道。检查所有偏移、长度、帧连续性与整数溢出。加密、未知结构或截断必须给出可解释失败；不复制或链接 GPL 提取器。原始裸 DSD 缺乏采样率、声道、位序时需要真实来源参数，不能静默猜测。

## 线程、资源与安全

复用现有 QtConcurrent/QFutureWatcher 与主线程回传惯例，采用本控制器拥有的有界队列与线程池。默认并发 2，建议最大 4，并按单任务内存和多声道 FFT 实测下调；文件夹发现也在后台进行，分批回传并限制列表增长。

`ReplayGainScanner` 本身没有取消能力，只能参考其回传方式。新控制器为应用级对象；工具页Loader切页会销毁，工具窗口关闭通常只是隐藏，两条路径都必须请求取消，不能仅依靠页面析构。应用最终退出时等待工作线程安全收敛，窗口交互过程中保持异步停止。

Decoder、FFT 缓冲和文件句柄只属于工作任务；worker 不捕获页面对象。GUI 线程更新 model。关闭页面/窗口和退出均触发取消；线程资源清理完成后才报告已停止，不在 GUI 线程无界等待。解码阻塞时显示“正在停止”。新增分析机制未激活时不启动线程、扫描或定时器。

单任务额外工作内存目标 ≤96 MiB；解码块、窗口队列、时频预览各设独立上限，超长文件不线性增长内存。取消在每个读取/FFT/写入安全点检查，目标 500 ms 内进入取消流程。

缓存键包含规范化路径、大小、修改时间、算法及参数版本，并为 ISO 包含区域/轨道；读取中和结束后复核身份变化。紧凑结果缓存目标约16 KiB/项，建议总量上限64 MiB并按最近使用淘汰；大时频矩阵不持久化。源文件始终只读，报告拒绝覆盖任何输入媒体；临时文件+原子替换失败须保留原有报告。
