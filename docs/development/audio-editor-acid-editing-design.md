# 音频编辑播放、片段手势与高质量变速变调设计

日期：2026-08-30

## 目标

在不恢复录音、不增加常驻后台服务的前提下，完成编辑器独占播放、波形范围框选、ACID 式单轨片段编辑、中央音量线精确命中、完整工具栏、两行快捷键与高质量实时变速变调。

## 已确认约束

- 打开音频编辑后由编辑器独占底层播放器；主播放器必须停止，二者不能同时出声。
- 音频工具处于音频编辑页时，首次 Space 即播放或暂停编辑时间线。
- 波形主体左键拖动创建时间范围；右键范围取消选择。
- 每个片段顶部 24 logical px 是片段操作带：单击选择、拖动移动、Ctrl+拖动复制。
- 片段左右 9 logical px 是不可见修剪命中区；分割后的片段拥有独立 ID、边界和选择状态。
- 中央综合音量曲线只有上下各 6 logical px 可命中；双击该曲线才添加 Envelope 点，点本身保留 18×18 logical px 命中区。
- 时间范围与片段选择是不同状态。剪贴板、删除、静音和淡变优先作用于片段选择；没有片段选择时才使用时间范围。
- 新工程默认保存 320000 bit/s。WAV 编码忽略该字段；MP3/AAC 默认选中 320 kbps。
- 快捷键提示固定两行，13 logical px；紧凑窗口可横向滚动，但不缩小字体。
- Signalsmith Stretch 1.3.2（提交 `57b93f4e9206a089a45387eaa39bdc9f310d3308`）作为高质量实时/离线处理引擎；SoundTouch 暂留为显式回退，不增加运行时 DLL。
- 不承诺数学意义的零失真；通过单次浮点处理、避免级联重采样、瞬态/频谱测试与可听 A/B 降低伪影。

## 播放所有权

`AudioEditorController::activate()` 请求编辑器所有权并调用主 `PlaybackController::stop()`；`deactivate()` 停止编辑预览并释放所有权。主窗口 Space 快捷键在音频工具窗口可见时禁用，音频工具 Space 使用 WindowShortcut，只调用 `AudioEditorController::playPause()`。

所有权切换只复用现有 `ag_player` 和 `EditorPlaybackAdapter`，不创建第二个播放器。首次播放失败必须显示现有错误覆盖层，不静默回退到主播放器。

## 时间线命中与选择状态

QML 命中优先级从高到低为：Envelope 控制点、音量曲线、左右修剪区、片段顶部操作带、波形范围框选。整块片段不再覆盖背景框选 MouseArea。

Controller 新增十进制字符串 `selectedEventId`。片段选择只用于编辑命令，不自动创建循环范围；范围选择继续控制循环播放。分割成功后选择右侧新片段；粘贴后选择新片段；撤销/重做后若 ID 不存在则清除片段选择。

命令目标规则：

1. `split`：在播放头处分割其下片段。
2. `delete/copy/cut/mute/fadeIn/fadeOut`：优先选中片段，否则使用有效时间范围。
3. `crop`：仅对时间范围有效。
4. `paste`：粘贴到播放头，生成新 ID 并选中新片段。
5. 片段拖动：普通拖动移动；Ctrl+拖动复制；一次手势只生成一个 Undo 项。

## 片段视觉

片段边界始终用 1 px 深蓝描边；分割接缝使用 1 px 高亮线。选中片段增加低透明蓝色覆盖和 2 px 焦点描边，不增加参考图之外的按钮或常驻标签。修剪命中区保持不可见。

## 变速变调处理链

`ITimePitchEngine` 接口不变，新增 `SignalsmithTimePitchEngine` 实现。配置使用 `presetDefault(channels, sampleRate, true)`；速率和音高在同一处理实例中完成，Formant 开关映射到 Signalsmith 的 formant compensation。1.0x/0 cent 时走直通，避免无效频域处理。

实时播放与导出共用同一引擎工厂和参数换算。参数变化时从当前时间线帧重建处理状态，不把已处理输出再次送入处理器。SoundTouch 只在 Signalsmith 初始化失败时使用，并向诊断日志记录一次回退原因。

## 验收

- 首次 Space 停止主播放器并启动编辑器；任何时候只有一个播放源。
- 波形主体可以框选；顶部操作带可以独立选择、移动和 Ctrl 复制片段。
- 双击非音量线区域不会增加控制点；双击曲线会增加，控制点可二维拖动且单步撤销。
- 分割、删除、裁剪、复制、粘贴、淡入、淡出、静音均产生可听且可撤销的真实结果。
- MP3/AAC 默认 320 kbps；快捷键在两行内完整可达。
- Signalsmith 与 SoundTouch 使用固定 WAV fixture 做时长、音高、瞬态和有限幅度测试；真实设备 A/B 另行记录，不能以自动测试冒充听感验收。
