# AgPlayer 交互与性能修复实施计划

> 目标：修复本轮 12 项人工验收问题；不打包 EXE，不改动无关用户代码。

## 1. 拖放、导入与波形

- 先补顶层原生拖放唯一分派测试，消除 Windows 原生拖放与 QML DropArea 的重复导入。
- 批量导入直接使用 `appendBatch()` 返回的歌曲 ID，删除逐文件全库扫描；验证大曲库导入期间 UI 不阻塞。
- 拖入后只加载并播放第一首一次，验证波形任务收到正确歌曲 ID、路径和时长。

## 2. 列表、菜单与排序

- 给内部歌曲拖动补齐 QML `Drag.keys`，验证单选、多选、重排和拖入普通歌单。
- 恢复并自动化验证右键菜单；菜单、悬停态使用系统深浅色令牌。
- 表头与行复用同一列规格，恢复艺术家列和玫红三柱播放动画；移除重复标题。

## 3. 筛选与曲库管理

- 搜索、评分、BPM 模块紧凑化；60/160 支持输入且滑轨长度不缩短。
- 曲库组合筛选放到 C++ 缓存模型中，避免 QML 重建大数组；增加 10K 行即时筛选基准。
- 缩小 BPM 滑块头；详情默认完整显示，空间不足时滚动，并按内容扩大默认窗口。

## 4. 音频工具与设置

- 四个工具窗口统一系统标题栏拖动/缩放入口，逐个跑真实导入、试听、删除和导出测试。
- 设置页改为紧凑 PC 栅格，相关小选项横向组合；波形画布默认 78px。

## 5. 播放器与频谱

- 顶部封面上移并圆角裁剪，歌曲信息相对封面垂直居中；波形紧贴顶部信息区。
- 频谱提高采样密度和高度，保持底座柱状、中间高两侧低。

## 6. 验证

- 目标测试先红后绿；运行全量 CTest、Release 构建和 QML 日志检查。
- 用真实 MP3/WAV/FLAC 验证拖放、播放、波形、工具与导出；打开程序供人工复验。
