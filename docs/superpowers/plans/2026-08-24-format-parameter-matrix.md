# Format Conversion Parameter Matrix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Limit the format-conversion workbench to MP3, FLAC, WAV, AAC, Opus, OGG, ALAC, and AIFF, with the documented defaults and selectable parameters producing real FFmpeg requests.

**Architecture:** Extend the existing capability catalog as the single source of UI choices and preflight validation. Keep `FormatConverter` as the QML facade and reuse the existing frozen conversion plan and linked-FFmpeg pipeline; no new dependency or parallel settings model.

**Tech Stack:** C++17, Qt 6/QML, Qt Test/QuickTest, linked FFmpeg, CMake/CTest.

**Spec:** `C:/Users/Administrator/Desktop/AgPlayer_音频格式转换参数推荐表.md` (parameter reference) and `docs/superpowers/specs/2026-08-12-format-conversion-remediation-design.md` (safety and acceptance contract)

## Global Constraints

- Output choices are exactly `mp3, flac, wav, aac, opus, ogg, alac, aiff` in that order.
- Preserve the supplied 2x4 format grid and current reference geometry; M4A remains a supported input/container where technically required, but is not an output choice.
- Source sample rate, bit depth, and channels are the default unless the selected format has a fixed constraint; Opus resolves to 48 kHz with explicit preflight evidence.
- Unsupported values fail preflight instead of being silently rewritten.
- Use existing Qt and FFmpeg dependencies only; preserve unrelated worktree changes.
