# AgPlayer Player Runtime Polish Implementation Plan

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Correct first-run shell selection, waveform completeness and rolling behavior, shared-list activation, separation setup UX, and immersive lifecycle/panel containment without changing unrelated playback or library behavior.

**Architecture:** Keep the existing Qt 6/QML controllers and shared components. Fix defects at their common source (`WaveformItem`/waveform cache, `TrackList`, separation controller, immersive renderer/window lifecycle) and make QML shells consume those corrected contracts. Avoid new frameworks and preserve portable external runtimes for large separation dependencies.

**Tech Stack:** C++17, Qt 6 Quick/QML, Qt Test/Quick Test, CMake/CTest.
