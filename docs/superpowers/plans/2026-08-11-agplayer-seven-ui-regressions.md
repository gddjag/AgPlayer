# AgPlayer 七项 UI 回归修复计划

## 范围

只修复歌曲列表停靠与跨屏、波形进度、主窗口纵向缩放、歌曲右键菜单、频谱峰值条、任务栏身份图标、EQ 视觉。音频工具内部实现不在本任务范围。

## 执行顺序

1. 用现有测试和 Windows 实机操作复现每个缺陷，记录窗口几何、点击结果和截图。
2. 为窗口几何、波形进度映射、峰值条位置、菜单真实触发、任务栏契约、EQ 字号补充会失败的回归测试。
3. 分别修复 DPI/停靠策略、统一波形时间轴、纵向缩放边界、菜单事件链、峰值条归一化、Windows AppUserModelID/图标、EQ 原生尺寸布局。
4. 运行定向测试与相关回归测试，再进行真实跨屏、拖拽缩放、播放点击和菜单验收。
5. 只暂存本任务文件，审查差异后提交；验收通过才生成新的桌面安装包。

## 完成标准

- 列表默认正好显示 10 首，始终贴齐播放器，跨不同 DPI 显示器不改变用户尺寸。
- 波形点击、已播放颜色、竖线使用同一时间映射，播放中平滑且缩放后仍重合。
- 主窗口宽高均能缩小，控件随可用区域缩放且不消失。
- 两个右键入口可真实点击并产生可观察结果。
- Peak Hold 始终位于对应柱体的最高位置并以常规速度下降。
- 任务栏分组身份稳定，窗口和安装后快捷方式图标一致。
- EQ 窗口与文字符合 Windows 常规视觉，无整体缩放导致的小字。
