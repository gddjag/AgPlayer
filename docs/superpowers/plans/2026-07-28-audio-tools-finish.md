# AgPlayer 音频工具收尾实施计划

> 按 TDD 红-绿-重构执行，每项完成后运行目标测试。

## Task 1：元数据策略

- 修改 `ag_transcode_options`、`TranscodeConfig`、`transcoder.cpp` 与 `FormatConverter`。
- 先增加保留/剥离元数据失败测试，再复制容器及音频流标签。
- 验证 MP3/FLAC 输出可解码且标签符合开关。

## Task 2：升降调高级选项

- 先增加平滑过渡边界能量测试。
- 实现首尾短等功率包络。
- 删除 Qt Bridge 的错误“不支持”完成提示。

## Task 3：BPM 节拍对齐

- 先增加起拍点估算和异步导出行为测试。
- 根据波形峰值估算前导拍偏移，变速后裁去缩放后的偏移。
- 对无可靠起拍点输入安全回退。

## Task 4：工具预览

- 新建 `AudioPreviewController` 及空后端单元测试。
- 注册为 QML 单例并接入调速、升降调页面。
- 验证播放、暂停、定位、音量和源文件切换。

## Task 5：本地化与 UI

- 移除所有工具页面“不支持”文案。
- 更新中/英/泰/越四套翻译。
- 运行 QML 测试和四语言三主题截图检查。

## Task 6：阶段验收

- Debug 全量构建与 CTest。
- 真实 WAV/MP3/FLAC 导出、元数据读取、空后端播放。
- 代码审查并修复重要问题。
- 更新阶段状态、刷新 codebase-memory 索引。
