# AgPlayer 无录音音频编辑器响应式收口设计

日期：2026-08-28
视觉基准：`C:\Users\Administrator\Desktop\音视频播放器\AgPlayer音频播放器完整版\音频编辑.png`

## 目标

在现有 Qt/QML 音频编辑架构上完成最小必要修改：正式删除录音功能，按最新参考图重建音频编辑页面，修复跨屏窗口、播放快捷键、时间线清空、选区循环、分割片段修剪和波形质量问题。不得恢复没有真实后端的“人声伴奏分离”占位实现，不新增第三方依赖。

## 已确认范围

- 保留四个真实可用工具页签：音频编辑、格式转换、元数据修改、文件名处理。
- 删除 `RecordingSession`、Controller 录音 API、录音 QML、录音快捷键、录音主题 Token、录音构建选项和录音测试。
- 右侧检查器固定为 A 速度/BPM、B 升降调、C 保持音调、D 导出设置。
- 底部重建为参考图中的当前时间区和全宽播放控制，不保留录音面板。
- 继续使用既有 `AudioDocument`、`EventTimeline`、`EditorPlaybackAdapter`、`EditorViewport` 和可见区峰值生成链。

## 窗口与布局

- `1672×941` 为像素级参考视口；标题栏 49 px、页签栏 43 px，其余内容按图片测量。
- 主区宽度始终由 `windowWidth - inspectorWidth` 得出；Inspector 宽度在 320–372 px 连续收缩，不再使用 `width >= 1500` 的二值布局。
- 时间线高度由窗口可用高度扣除命令栏、信息条、播放控制和快捷键卡后连续计算。
- `1280×720` 保持主区和可滚动 Inspector；`880×560` 使用主区优先及可展开覆盖式 Inspector，播放和导出入口始终可达。
- 标题栏拖动改用系统原生移动；跨 DPI 时接受 Windows 建议矩形并保持逻辑尺寸，取消音频工具窗口的旧物理像素尺寸锁定。

## 播放与快捷键

- 音频编辑页处于当前工具时，Space 始终播放/暂停；当前焦点位于按钮、滑块、下拉框或时间线控制点时也不得触发焦点控件。
- 唯一 Space 快捷键提升到音频工具窗口层；文本输入编辑期间除外。
- 运输控制为上一段、后退、播放/暂停、前进、下一段、停止，并绑定现有真实 Controller 能力。
- 点击选区外的位置先取消选区循环，再定位播放头；点击选区内只定位播放头并保留循环。

## 时间线编辑

- “清除”执行可撤销的时间线事件清空，保留工程壳、导出设置和 Undo 历史；一次操作对应一个 Undo 项。
- 创建有效选区即默认启用循环；播放到选区末端返回选区起点。
- 右键任意选区区域取消选区及循环。
- 分割继续使用字符串 Event ID 和现有事务式编辑。
- 相邻、同源、同参数的分割片段使用共享边界联动修剪：向一侧拖动时，一个片段伸长、相邻片段等量缩短；不引入重叠混音语义；整次拖动只有一个 Undo 项。
- 保留中央片段 Gain 线、双击添加 Envelope 点、Envelope 点的时间/增益二维拖动和右键删除。

## 波形

- Controller 只发布一个混合包络；QML 只画一条中央基线。
- 立体声混合使用不会因反相声道抵消的幅度/能量包络，输出为对称 `[-amplitude,+amplitude]`。
- 深度缩放优先解码当前可见 PCM，按设备像素比提高请求密度；渲染层使用连续插值和抗锯齿，空隙仍用 NaN 隔断。
- 点数保持有界，不超过 `2 × viewport logical width × DPR` 的峰值桶预算。
- 异步任务区分“真实空隙”和“解码暂不可用”；后者不得用全空结果覆盖 last-good 波形，仅最新 generation 可发布。
