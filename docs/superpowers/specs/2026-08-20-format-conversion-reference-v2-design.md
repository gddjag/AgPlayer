- 窗口固定参考尺寸改为 `1672×941`；继续支持现有最小尺寸和最大化。
- 标题栏高 48 px，品牌文案、Logo、窗口按钮位置按图片测量。

### 页面四区

- 工具栏高 60 px；按钮顺序、搜索框、漏斗筛选按钮与参考一致。
- 主区左右间距 8 px；左任务区优先伸展，右设置区参考宽度 445 px。

- 右面板 A/B/C 三组默认视图完整显示提示卡；高级并发项位于内部滚动区域下方，不改变默认截图。
- 底栏高 114 px，只显示左侧总进度/任务与 ETA、中部完成/失败统计、右侧开始和取消按钮。

### 交互

- 所有导入、筛选、选择、格式、参数、输出选项、预检、开始、取消和错误入口继续绑定真实后端。
- 行右键菜单复用当前任务 API：移除、失败重试、取消活动任务、复制错误；打开目录仅在已有跨平台接口可复用时启用，不新增系统抽象。
- 设置面板折叠箭头真实切换折叠状态；折叠时任务表占用剩余宽度。
- 参考图混合状态通过测试专用 QML 夹具生成，不在产品二进制中注入示例任务。

## 真实预检与执行

- `buildPreflight(request)` 将当前勾选任务转换为 `FormatPlanInput`，将 QML 请求转换为 `FormatConversionRequest`，调用现有 `build_format_conversion_plan()`。
- `pendingPlan` 保存冻结后的请求、任务 ID、解析参数、输出路径、差异和确认需求；错误在开始前返回。
- `confirmPendingPlan()` 只执行冻结计划中的任务，不重新读取可变 UI 参数；被移除或失效的任务必须拒绝启动。
- 运行任务继续走现有 `startJobs → runTranscode → ag_transcode_v2 → staging 校验 → commit` 链路，不引入外部 `ffmpeg.exe`。
- 输出目录初始化为 `SettingsController.defaultOutputDirectory`，用户编辑或选择后写回设置系统。
- 不在本轮加入响度标准化；旧兼容参数保留但不在 UI 暴露，也不声称已实现。

## 错误、安全与性能

- 保留文档规定的同目录临时文件、完整解码校验、原子提交、取消清理、Unicode 路径和冲突策略。
- 预检失败必须显示具体原因；任务失败保留阶段和诊断；取消不计为失败。
- 任务模型继续使用 `QAbstractTableModel` 与代理模型，进度通过现有节流路径更新；不得在 QML 创建每任务重量对象。
- 不修改播放器实时音频线程，不增加常驻服务或第三方依赖。
