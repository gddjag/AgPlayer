# AgPlayer 自定义主题功能彻底移除设计

## 目标

从当前 Qt/QML 播放器中彻底移除自定义主题皮肤能力，同时保留且只保留三种外观：跟随系统、浅色、深色。深色是缺省、非法值回退和“恢复默认”的目标模式。

颜色选择能力本身不删除。波形、频谱等既有媒体颜色继续可编辑，其 `ColorField` 恢复到自定义主题开发前使用 Qt 原生 `ColorDialog` 的样式与确认行为。

## 已确认边界

- 不整合其他分支，不重写或重置当前共享历史。
- 不打包 EXE，不推送远端。
- 不修改波形、频谱、RGB 三频、音频编辑器、Equalizer、CUE、评分、标签等媒体或领域颜色的含义和默认值。
- 不主动删除用户磁盘中遗留的自定义皮肤键；新代码不再读取、写入或应用这些键，避免不可逆破坏降级数据。
- 保留当前分支中与主题无关的音频工具、列表、元数据和多语言改动。

## 选定方案

在当前干净 HEAD 上新增一个可审查的回退序列，按源码职责删除自定义主题能力，不通过隐藏设置入口或保留失效代码实现“伪删除”。

不采用回退到旧提交后重新挑选非主题提交的方案。当前历史中主题提交与音频工具、列表和 QA 修正交错，重建历史会增加误删无关功能的风险。

## 架构回退

### 外观模型

保留现有持久化数值语义，避免破坏旧设置：

- `Dark = 0`
- `Light = 1`
- `System = 2`

设置页显示顺序为“跟随系统 / 浅色 / 深色”，深色明确标记为默认。合法的已有 `themeMode` 继续生效；键缺失、值越界或恢复默认时使用 `Dark = 0`。

### Theme 实现

- 删除自定义皮肤用的 C++ `ThemeManager`、动态 Seed/Gradient/Glass Palette、推荐色和 QML 单例注册。
- `Theme.qml` 恢复为固定 Light/Dark Token 源；System 只负责实时选择 Light 或 Dark。
- 保留现有兼容 Token 名称，使普通 QML 控件继续使用统一颜色，而不做全项目改名式重构。
- Default 激活色、当前播放行和媒体专用色恢复到三主题实现原有定义，不再从用户皮肤派生。

### 设置与持久化

从 `SettingsController`、设置事务、QML 和测试中删除：

- `skinColorMode`
- `skinPreset`
- `skinCustomKind`
- `skinCustomColor`
- `skinCustomColorMiddle`
- `skinCustomColorEnd`

删除相关信号、编辑快照、Commit/Cancel/Reset 分支和 QA 参数。旧 Accent/Highlight/skin 磁盘键均成为惰性遗留数据，不参与运行时状态。

### UI 与资源

- 设置页删除“主题皮肤色”、推荐渐变、单色/三色自定义等所有皮肤 UI。
- 删除 `ThemeColorSelector`、`AgColorPicker`、`ColorScale.js`、`SkinBackdrop` 及其 QML 模块注册。
- 各窗口恢复普通不透明主题背景；删除渐变/玻璃背景插入点。
- `ColorField.qml` 恢复原生 `QtQuick.Dialogs.ColorDialog`，继续服务波形和频谱颜色编辑。
- 标签管理原有 `ColorDialog` 保持不变。
- 删除自定义皮肤专用翻译上下文、静态合同、截图参数和验收文档；保留三主题和媒体颜色所需文案与测试。

## 数据与兼容

删除功能后，启动流程只读取 `appearance/themeMode`。合法旧值保持原语义；非法值立即归一化为深色并按现有设置策略持久化。

旧皮肤键不再产生任何可见效果。因为不主动擦除，这些键不会影响新版本，也允许用户回退旧版本时保留原数据。

## 测试策略

先写或改测试，再删实现：

1. `SettingsController`：缺省/非法/Reset 为深色，三种合法值保持兼容，设置事务只处理 `themeMode`，媒体颜色不受影响。
2. QML 设置页：只存在三种外观按钮，不存在皮肤选择器、推荐色、自定义色或渐变控件。
3. Theme 合同：Dark/Light Token 精确回归；System 随系统方案切换；普通窗口不再创建 `SkinBackdrop`。
4. 颜色选择器：波形/频谱 `ColorField` 使用原生 `ColorDialog`，接受时更新目标颜色，取消时不修改。
5. 静态检查：源码、QML 模块、翻译和 QA 参数中不存在自定义皮肤运行时代码或死资源。
6. 验证：Debug/Release 构建、聚焦 CTest、QML lint、静态检查、Release 全量 CTest、Debug 全量基线、三模式截图和真实 WAV smoke。

## 完成判定

- 设置中只能看到“跟随系统 / 浅色 / 深色（默认）”。
- 重启、取消设置、保存设置和恢复默认行为一致。
- 搜索和构建产物中不存在可调用的自定义皮肤功能、渐变背景或主题专用 Picker。
- 波形与频谱原有颜色选择仍可用，并恢复原生取色器样式。
- 非主题功能没有被删除或重置。
- 最终只提交源码、测试、翻译和验收记录；不整合分支、不打包、不推送。
