# AgPlayer 音频工具收尾设计

## 目标

关闭格式转换、调速 BPM、升降调页面仍对用户显示的“不支持”状态，同时保持 Core / Qt Bridge / QML 三层边界，不影响主播放器队列。

## 已选方案

1. **格式转换元数据**
   - `ag_transcode_options` 增加 `keep_metadata`。
   - Core 在写容器头前按开关复制容器与音频流元数据。
   - 关闭开关时不复制任何输入标签；封面等附加流不进入纯音频转码输出。

2. **升降调高级选项**
   - 保留已实现的人声保护滤波。
   - `smooth_transition` 在处理后音频首尾施加短等功率淡入淡出，消除边界点击声。
   - Qt Bridge 仅在真实失败时报告错误，成功统一返回完成信号。

3. **BPM + 节拍对齐**
   - BPM 调整仍以检测 BPM 与目标 BPM 计算精确时间比例。
   - 开启节拍对齐时，从已分析波形估计首个有效起拍点；变速后用轻量剪辑去除对应前导偏移，使第一拍落在时间零点。
   - 没有可靠起拍点时保留完整输出并正常完成，不伪报对齐失败。

4. **独立预览**
   - 新增一个 Qt Bridge 预览控制器，内部使用独立 `ag_player`，不占用、不重置主播放器。
   - 调速、升降调页面可播放/暂停原始素材、定位和调节预览音量。
   - 工具窗口关闭或应用退出时停止并释放预览实例。

5. **主题与本地化**
   - 新状态和提示使用 `qsTr`，只维护中文、英文、泰语、越南语。
   - 图标继续使用现有主题色令牌，适配深色、浅色、跟随系统。

## 验收

- 不再出现音频工具相关 “not supported” 文案。
- 元数据保留和剥离均有真实文件测试。
- 平滑过渡可测量地降低首尾边界幅度。
- 节拍对齐输出首个有效起拍点接近零点。
- 独立预览不改变主播放器状态。
- Debug 全量构建、CTest、四语言三主题 QML 检查、WAV/MP3/FLAC 导出和空后端播放全部通过。
- 本阶段不封装 EXE。
