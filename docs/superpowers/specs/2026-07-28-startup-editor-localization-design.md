# AgPlayer 启动页、轻度剪辑与四语言设计规格

## 目标

在现有 Qt 6 / QML + C++17 架构中完成三项连续交付：

1. 按最新参考图将空白启动页精确调整为 1228×424。
2. 将应用语言严格收敛为中文、英文、泰语、越南语，并真正加载翻译。
3. 将轻度剪辑升级为最多六轨、支持 BPM 统一和节拍对齐的非破坏性编辑器。

不封装 EXE。每个阶段必须完成自动测试、运行截图、自检和修复。

## 方案选择

采用“扩展现有能力”的方案：

- 复用 `LightEditor`、`multitrack_edit`、`SpeedAdjuster`、`BpmAnalyzer`。
- 扩展现有轨道数据，不创建第二套剪辑或 BPM 引擎。
- QML 只负责交互状态和呈现；文件分析、变速、渲染继续由 C++ 异步执行。
- 继续使用现有主题、窗口控制、错误提示和任务取消机制。

不采用以下方案：

- 仅制作静态编辑器界面：无法满足真实编辑和导出要求。
- 引入第三方 DAW/时间线 SDK：依赖和集成成本过高，当前功能不需要。

## 阶段一：空白启动页

### 窗口与布局

- 空白启动窗口默认尺寸：1228×424。
- 保持无边框、圆角、深色背景和当前品牌标识。
- 顶部品牌位于左上角；设置、最小化、最大化、关闭位于右上角。
- 标题、说明、打开文件、导入文件夹、格式提示按参考图居中。
- 底部控制栏保持左右端按钮和居中的播放控制组。
- 所有图标使用透明背景；仅悬停、按下或键盘聚焦时显示交互反馈。

### 自适应

- 最小宽度以下保持核心按钮可见，不发生重叠。
- 有媒体后仍切换到正式播放页，不改变已有播放页结构。
- 深色、浅色、跟随系统三种主题均使用语义颜色和对应图标颜色。

### 验收

- 使用相同 1228×424 视口生成实现截图。
- 参考图与实现图并排比较。
- 修复所有 P0、P1、P2 视觉问题后才进入下一阶段。

## 阶段二：四语言

### 支持范围

仅支持：

- `zh`：简体中文
- `en`：English
- `th`：ไทย
- `vi`：Tiếng Việt

移除设置页和校验逻辑中的韩语、缅甸语、老挝语等选项。历史设置若包含不支持的语言，自动回退为中文。

### 实现方式

- 使用 Qt Linguist 的 TS/QM 资源和 `QTranslator`。
- 启动时加载已保存语言；运行时切换语言后刷新 QML 文本。
- 所有新增界面字符串必须使用 `qsTr()` 或 C++ 可翻译字符串。
- 四种语言至少覆盖主窗口、空白启动页、设置页、音频工具、轻度剪辑和通用错误提示。

### 验收

- 测试四个有效代码均被接受。
- 测试其他代码回退中文。
- 启动页和轻度剪辑分别进行四语言截图，检查截断、溢出和错位。

## 阶段三：六轨轻度剪辑

### 轨道模型

最多六轨。每条轨道保存：

- 输入路径、文件名、时长、波形峰值。
- 原始 BPM、BPM 置信度、目标 BPM、变速比例。
- 片段起点、素材入点、素材出点。
- 淡入、淡出、增益、静音、独奏、锁定。
- 是否已完成 BPM 统一和节拍对齐。

编辑状态为非破坏性数据；原始文件不被覆盖。

### 时间线交互

- 点击轨道或片段进行选择。
- 拖动片段主体改变时间线起点。
- 拖动左右边缘改变素材入点和出点。
- 默认吸附到目标 BPM 的 1/4 拍网格；可关闭吸附。
- 锁定轨道禁止移动和裁剪。
- 鼠标滚轮以指针所在时间为锚点缩放。
- `Shift + 滚轮` 或横向拖动时间标尺平移视口。
- 播放头、片段和时间标尺使用同一毫秒坐标系。
- 所有移动和裁剪值限制在有效范围内，片段最短时长为 200 毫秒。

### BPM 功能

- 加载文件后可分析原始 BPM。
- 顶部目标 BPM 支持加减和直接输入，范围 40–240。
- “统一 BPM”仅按目标 BPM 进行保持音高的速度转换。
- “BPM + 节拍对齐”先统一 BPM，再将片段首个有效拍点吸附到共享网格。
- 单轨失败不伪装成功；界面显示具体轨道和错误原因。
- 处理任务支持取消，不阻塞界面。

### 编辑工具

首轮真实实现：

- 撤销、重做。
- 裁剪、删除、分割。
- 淡入、淡出。
- 静音、独奏、锁定。
- BPM 统一和节拍对齐。

复制、粘贴、合并只有在数据模型和导出语义明确后再启用；本轮不得显示为可用却无实际效果。

### 导出

- 复用多轨渲染器，输出混合后的单个音频文件。
- 渲染应用时间线起点、入点、出点、淡入、淡出、增益和静音状态。
- BPM 处理生成的临时素材放入应用缓存目录，成功、取消或失败后按规则清理。
- 输出格式首轮支持 MP3、WAV、FLAC；采样率和声道按界面选择。
- 输出路径不能覆盖任何输入文件。

## 数据流

1. QML 请求导入文件。
2. `LightEditor` 异步探测元数据、波形和 BPM，并更新轨道模型。
3. QML 将拖动、裁剪、吸附操作转换为毫秒参数并提交到轨道模型。
4. BPM 命令调用现有变速能力生成缓存素材。
5. 导出命令将六轨编辑状态转换为多轨渲染配置。
6. C++ 发出进度、完成、取消或具体错误信号；QML只展示真实状态。

## 错误处理

- 无文件、损坏文件、不支持格式、无写入权限、输出路径冲突均返回明确错误。
- BPM 无法可靠识别时保留原速度，并要求用户手动输入原始 BPM。
- 处理中关闭窗口先请求取消，再等待后台任务安全结束。
- 不记录用户音频内容；日志只记录路径、状态码和必要诊断信息。

## 测试策略

### C++ 自动测试

- 轨道数上限和索引边界。
- 片段移动、裁剪、最短时长和锁定规则。
- 1/4 拍吸附计算。
- BPM 比例范围和无效 BPM。
- 六轨渲染参数映射、取消、失败和输出冲突。
- 四语言代码校验和历史设置回退。

### QML 自动测试

- 启动页 1228×424 布局和关键控件。
- 深色、浅色、跟随系统。
- 四语言选项。
- 六轨显示、选择、拖动、裁剪、滚轮缩放和吸附开关。
- BPM 按钮状态、进度和错误提示。

### 手工与视觉测试

- 启动页参考图与实现图并排对照。
- 轻度剪辑参考图与实现图并排对照。
- 四语言、三主题、100%/125%/150% Windows 缩放。
- 真实音频导入、BPM 处理、对齐、试听和导出。
