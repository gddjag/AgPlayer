# AgPlayer 参考风格频彩波形校准设计

日期：2026-09-03

## 目标

在既有 Low / Mid / High 单套分析、缓存和渲染链路上，把频彩波形从长期偏橙黄的结果校准为层次丰富、频段可读、视觉接近用户提供的 rekordbox 参考图的三色加法光效果。只参考公开可见的视觉特征，不复制第三方代码、资源或未公开算法。

默认基色固定为 Low `#FC0909`、Mid `#03FF00`、High `#0048FF`。设置页仍只允许用户修改这三个基色；算法标定参数不进入用户界面。

## 约束

- 波形高度只由原始混合振幅 `mix` 决定。
- 播放进度只改变 Alpha，不改变色相、饱和度、亮度或几何。
- 保持一个 `WaveformBucketizer`、一个 `.agwf` 缓存和现有 QSG 渲染节点。
- 不恢复 FFT、Hann、Spectral Centroid，不增加 ShaderEffect、第三方依赖、线程或后台任务。
- 主波形和列表缩略图消费同一份 `mix/low/mid/high` 数据和同一个混色函数。

## 频段能量

继续使用现有 250 Hz、4 kHz 边界和轻量 IIR 分频。每个频彩桶独立于波形高度聚合方式，保存三路平方和与绝对峰值；完成时计算：

```text
rms = sqrt(sumSquares / sampleCount)
rawBand = 0.80 * rms + 0.20 * peak
```

三路不再共用单一最大值，也不完全独立拉满。对每路计算整曲非零有限值的 95% 分位数 `bandP95`，令 `globalP95` 为三路 `bandP95` 的最大值：

```text
reference = 0.15 * globalP95 + 0.85 * bandP95
normalized = clamp(rawBand * bandGain / reference, 0, 1)
```

频段增益固定为 Low `0.90`、Mid `1.00`、High `1.50`。小于 `bandP95 * 0.015` 的数值视为零。全静音和无有限参考值时三路输出全零。这组常数来自旧算法独立 RED 夹具的实测校准，用于保证同幅短高频不会再次被低、中频完全压住。

分析结果仍是每桶三个 `[0,1]` 浮点数，不增加缓存字段。`.agwf` 文件格式保持 v4，但缓存键的分析修订号提升到5，使旧三频能量缓存安全失效并走现有重建路径。

## 颜色传递

渲染时对每路归一化能量执行：

```text
compressed = pow(clamp(energy, 0, 1), 0.55)
weight = pow(compressed, 1.20)
```

三个用户基色从 sRGB 解码到线性光空间，按未归一化权重做加法混合。混合后的每个线性通道用归一化软拐点映射：

```text
softKnee(x) = clamp((1 - exp(-1.35 * x)) / (1 - exp(-1.35)), 0, 1)
```

再编码回 sRGB。只激活一个频段且能量为满值时返回精确基色；无活跃频段时返回透明度由调用方管理的 Low 基色，保持现有空桶兼容行为。删除现有 HSL 饱和度和亮度强制恢复，避免扭曲频段比例。

## 渲染塑形

频彩主波形的每根竖线拆成上半和下半两个线段，边缘使用中心颜色的72%线性亮度和55% Alpha，中心使用108%线性亮度和原 Alpha。使用现有 `QSGGeometry::ColoredPoint2D` 顶点插值完成，不创建 ShaderEffect 或额外场景图节点。

普通波形、RGB波形和柱状频谱保持原几何与颜色行为。列表缩略图继续使用现有三频混色函数；其高度太小，不额外翻倍顶点，只通过新颜色传递获得综合色彩改善。

## 验收

- 80 Hz、1 kHz、10 kHz 单频分别由 Low、Mid、High 主导。
- 同等幅度的低中、中高、低高组合分别产生黄、青、品红方向颜色；三路满能量接近白色。
- 高频短脉冲在输出中保留可见 High 峰值，不被整桶 RMS 完全抹平。
- 安静段不会因独立归一化把微弱频带噪声拉满。
- 默认、重置和持久化颜色为 `#FC0909/#03FF00/#0048FF`，设置页没有新增算法参数。
- 频彩主波形中心比边缘更亮且边缘 Alpha 更低；播放进度仍只缩放整体 Alpha。
- 旧缓存键失效，新缓存仍为一份 v4 `mix/low/mid/high` 文件。
- 聚焦测试、Debug 构建、真实播放器截图和最终 Diff Review 完成后才报告实现完成。

## 非目标

- 不宣称复刻 rekordbox 的内部算法或逐像素输出。
- 不增加 Attack-Release、FIR、FFT、GPU着色器或高级用户调节项。
- 不修改普通波形、播放、音频输出、队列或其他设置行为。
