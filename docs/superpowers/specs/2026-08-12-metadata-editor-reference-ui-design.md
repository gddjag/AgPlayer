# 元数据编辑参考 UI 完整实现设计

## 目标与基准

以 `元数据修改.png` 为唯一视觉基准，以桌面上的《AgPlayer 元数据修改模块开发提示词（正式版）》为功能与安全基准。保持 AgPlayer 现有 Qt 6/QML 深色设计系统，不重构无关播放、波形、剪辑或文件名模块。

## 可选实现路径

1. **推荐：现有页面深度补全。** 保留 `MetadataEditPage.qml`、`MetadataEditor`、`metadata_writer` 和 `FormatConverter` 现有边界，补齐缺失状态、能力报告、预检决策、列表行为和库刷新。改动最小，能复用当前已通过的流复制与转换链路。
2. 新建独立元数据工具子系统。边界更纯，但会重复文件发现、任务管理和格式转换能力，迁移风险高。
3. 只做截图外观。成本最低，但不满足真实预检、取消、安全替换与结构化结果要求，拒绝采用。

## UI 结构

- 顶部维持四个音频工具标签，元数据编辑高亮。
- 工具栏依次为添加文件、添加文件夹、从播放列表添加、移除选中、清空列表；右侧为文件名/标签/路径搜索和状态/格式筛选入口。
- 主区为 62:38 左右分栏。左侧固定表头和底部状态栏，中间列表可滚动；右侧自身可滚动，缩放时不得挤出画布。
- 左表列为选择框、文件名、标题、艺术家、专辑、年份、时长、封面、状态。列头可排序，底部提供全选、已选/总数及导出当前列表。
- 右侧先显示作用范围和处理方式，再显示九个文本字段三态编辑、独立封面三态、实时修改摘要和逐文件预检结果。
- 底栏显示影响文件数、真实进度、预检、导出结果、取消和主按钮。转换模式主按钮进入现有格式转换流程。

## 交互与状态

- 当前文件由焦点行决定；已选文件由勾选集合决定；全部文件始终指完整任务模型，不受搜索和筛选影响。
- 九个文本字段只有保留、设为、清除。设为时输入框可用且空值阻止执行；多选值不一致显示“多种值”。年份和日期同时编辑时报告物理标签冲突。
- 封面支持保留、替换、移除；显示实际缩略图、文件名、分辨率、MIME/格式与大小；多文件不一致显示“多种封面”。
- 应用修改必须先执行异步逐文件预检。全部通过才直接执行；存在不支持项时弹出决策：取消、跳过不支持项继续、只处理完全支持的文件。默认不隐式跳过。
- 任务状态至少覆盖就绪、预检中、等待处理、正在写入、正在验证、已完成、部分完成、不支持、失败、已取消。
- 取消会标记未开始文件，并通过 core 取消令牌在 packet 循环和原子替换前安全停止当前文件。

## 架构与数据流

- `metadata_writer` 维护容器无关的字段/封面 Edit Plan、能力报告、稳定错误码、字段结果、验证结果和文件结果；QML 不接触 FFmpeg 键名。
- `MetadataEditor` 负责异步发现、读取、作用范围、预检、批处理、取消、进度、结果导出及 Qt 数据模型；所有 FFmpeg I/O 在工作线程。
- `FormatConverter` 接收同一 Edit Plan，并在输出 header 前应用元数据；转换模式输出新文件，不覆盖源文件。
- 成功后通过现有 `LibraryModel.applyMaintenanceResults` 批量刷新路径对应的标题、艺术家、专辑、年份和封面，保持选择与滚动位置。

## 安全与错误

- metadata-only 固定同容器重封装和 packet stream copy，不创建解码器或编码器。
- 临时文件位于源文件同目录，写完后重新探测、字段回读、封面验证和音频流等价验证，全部通过后才原子替换。
- 预检包含文件存在/常规文件、只读、目录可写、磁盘空间、文件占用、容器/muxer/字段/封面能力及外部修改检测。
- 结果记录稳定错误码、原始错误、用户提示、文件、字段和阶段；任何异常都不得造成应用崩溃或假成功。

## 测试与验收

- core：Keep/Set/Clear、别名、年份/日期冲突、BPM、Unicode、容器能力、封面、取消、安全回滚、零解码/编码指标。
- Qt：三个作用范围、搜索不影响全部范围、异步预检、决策策略、批量进度/取消、结果统计/导出、曲库刷新、转换 Edit Plan 复用。
- QML：三态互斥、输入启用、混合值、封面状态、按钮启用、排序/搜索/筛选、响应式布局和对话框。
- Release 构建及真实桌面交互：按参考分辨率和 100%/125%/150%/200% 缩放比较截图，完成添加、选择、预检、修改、取消、转换跳转和报告导出。

## 范围边界

- 不增加音轨号、碟片号、评论或歌词。
- 不复制新的转码参数面板，不使用外部 `ffmpeg.exe`，不打包 EXE。
- 若当前 FFmpeg 构建对某容器/字段/封面不支持，必须显示真实 Unsupported，不伪造完成。
