# AgPlayer 桌面外壳与音频工具可靠性修复设计

**日期：** 2026-08-13  
**状态：** 用户已批准执行  
**基线：** `63cfb8c`，Release 测试 74/74 通过

## 目标

本轮只修复已报告的七类失效，不重做已有音频工具，也不打包：

1. Windows 任务栏使用稳定应用身份、图标和可固定的重启信息。
2. 所有评分星星统一为纯橘黄色，不再使用渐变色阶。
3. “最近添加 / 从未播放”通过真实分类筛选工作。
4. 格式转换使用能力驱动的智能预设与高级参数，预检拒绝不兼容组合。
5. 音频编辑器补齐播放头拖动、选区边缘调整、缩略波形平滑拖动、录音和速度/音高交互。
6. 元数据页面的字段编辑可以直接产生并执行真实修改计划。
7. 文件名处理同时支持添加和删除前缀、后缀、序号，并支持单项和批量。

## 方案

### Windows 外壳与评分

进程和顶层窗口继续使用 `AgPlayer.Desktop`。在已有显式 AppUserModelID 基础上，为窗口属性存储补齐 RelaunchCommand、RelaunchDisplayNameResource 和 RelaunchIconResource，使任务栏固定后能稳定重启同一应用并使用同一图标。安装器快捷方式继续使用相同身份。

主题只保留一个评分强调色；`ratingColor()` 对每一颗星返回同一个橘黄色。未评分星仍使用普通前景色。

### 曲库分类

新导入记录在入库时写入同一批次的 `addedAtMs`。旧数据库缺失该字段时，用源文件创建时间或修改时间迁移，避免“最近添加”永远为空。“从未播放”继续以 `playCount == 0` 为唯一标准，播放计数变化后代理模型立即重新筛选。

### 格式转换

格式能力是唯一参数来源。每种可用格式提供“推荐 / 高质量 / 兼容 / 自定义”预设；无损格式不显示码率模式，有损格式只显示编码器实际支持的 CBR/VBR 与码率。声道默认自动，Opus 等格式的采样率约束在预检阶段归一化并明确展示。

预检冻结实际执行参数，检查格式、码率模式、码率、采样率、采样格式和声道布局。任何调整进入确认摘要；无法执行的组合在排队前失败。质量参数从 QML 一直传到转码核心，不再使用硬编码值。

### 音频编辑交互

主波形采用明确的交互优先级：播放头手柄 > 左右选区手柄 > 新建选区。拖动播放头只 seek，不改变选区；拖动选区边缘只修改对应边界；在空白波形拖动才新建选区。所有命中区大于可见线宽。

缩略波形窗口记录按下偏移量，拖动过程中连续移动视口，不在按下时跳变。录音设备启动和停止/收尾不阻塞 GUI 线程，并显示启动、录制、暂停、收尾、失败状态。右栏给出可见的开始、暂停/继续、停止与刷新设备操作。速度、BPM、半音和音分与控制器双向同步，并提供预览、应用、复位。

### 元数据与文件名

元数据字段行显式引用自身模式和字段键；用户直接编辑即切换为“设为”，清空按钮切换为“清除”。应用按钮由真实修改计划驱动，预检和写回后重新读取验证。

文件名处理拆成“添加”和“删除”两组。删除支持自动识别、精确前缀、精确后缀、开头序号和结尾序号；预览使用与提交相同的规则，但测试以实际重命名结果为准。选中项执行单项/多项，未限定时执行整批。

## 安全与失败处理

- 文件写入继续使用同目录临时文件、验证、原子替换；失败不损坏源文件。
- 录音和转码的慢操作不占用 GUI 线程；取消和失败都恢复可操作状态。
- 不可用编码能力明确禁用并显示原因，不做静默降级。
- 不新增外部运行时，不启动外部 `ffmpeg.exe`。
