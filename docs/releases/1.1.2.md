# AgPlayer 1.1.2

2026-10-16

## 中文

- 同步 Windows、macOS、Android 与鸿蒙版本号为 1.1.2。
- 修复音频工具的文件传递、元数据编辑和时间线播放交互；调整 BPM、波形选区和标签显示。
- Windows/macOS 双窗口关闭歌曲列表后，歌词显示在播放器下方；歌词界面不再显示来源信息。
- 官网 Android 版在同意隐私政策后检查更新，下载后校验安装包并交由系统确认安装；伴奏分离模型已内置。
- 鸿蒙 PC 移除“支持作者”入口；鸿蒙手机版与华为 Android 版保留内购支持作者。商店包由开发者另行提交。
- Android 1.1.2 使用新签名，无法覆盖安装旧版 APK。macOS 通用包支持 Intel 与 Apple Silicon，采用临时签名，尚未经过 Apple 公证；首次打开可参阅 [Apple 官方教程](https://support.apple.com/zh-cn/102445)。

## English

- Version 1.1.2 is synchronized across Windows, macOS, Android, and HarmonyOS.
- Fixes cover audio-tool file handoff, metadata editing, timeline playback, BPM controls, waveform selections, and tag display.
- In Windows/macOS dual-window mode, lyrics appear below the player after the library window closes. Lyrics views no longer show source information.
- The Android website edition checks for updates after privacy consent, verifies downloaded packages, and uses the system installer. Separation models are bundled.
- HarmonyOS PC removes Support the Author; HarmonyOS mobile and Huawei Android retain in-app support purchases. Store packages are submitted separately by the developer.
- Android 1.1.2 uses a new signing key and cannot install over an older APK. The Universal macOS package supports Intel and Apple Silicon, is ad-hoc signed, and is not Apple-notarized. See [Apple's official opening guide](https://support.apple.com/zh-cn/102445).
