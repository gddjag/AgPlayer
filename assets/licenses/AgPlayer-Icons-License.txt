AgPlayer UI Icons Notice
=========================

AgPlayer project icons
----------------------

Except for the files listed below, the SVG files under assets/icons/ are
original works created by the AgPlayer project. Their visual style (24x24
viewBox, currentColor fill) is inspired by the Remix Icon layout convention,
but their path data is hand-authored for AgPlayer.

Icons not listed in the third-party section below remain AgPlayer project
assets and retain the license that applies to the AgPlayer source tree.
