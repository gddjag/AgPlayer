AgPlayer UI Icons
=================

The SVG files under assets/icons/ are hand-authored by the AgPlayer project,
visually inspired by the Remix Icon library (https://remixicon.com/) layout
conventions (24x24 viewBox, currentColor fill). They are original path data
written for AgPlayer, not copies of upstream Remix Icon SVGs.

AgPlayer project contributors license these icon SVGs under the same license
as the AgPlayer source code.

Reference: Remix Icon is licensed under the Apache License 2.0
(https://github.com/Remix-Design/RemixIcon/blob/master/License).
