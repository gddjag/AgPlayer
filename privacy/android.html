华为应用市场版

AgPlayer Android 华为应用市场版隐私政策

AgPlayer Android 版是一款本地音乐播放和音频处理应用，无需注册或登录。本渠道在您同意本政策并进入首个稳定主界面后，连接华为应用市场联运服务完成初始化及官方版本检查；仅当您主动打开“支持作者”时，连接华为应用内支付服务。更新由华为官方组件和应用市场界面提示、处理并由您确认，本渠道不接入官网更新或开发者自建下载安装机制。本应用不提供在线歌词、模型下载、云端处理、AgPlayer账户或同步功能。音频、录音和处理结果在设备本地处理，不上传给开发者。

一、本地文件与数据

您主动选择本地歌曲、文件夹或输出位置后，本应用读取或写入您授权的内容，用于播放、音乐库管理、波形和 BPM 分析、录音和音频工具。“下载来源”仅扫描您授权的本地下载或接收文件夹，不提供联网下载。保存六轨工程时，会把所用源音频副本与工程文件写到您选择的同一目录。歌单、收藏、评分、标签、播放记录、设置、处理记录和缓存保存在本机；伴奏分离模型随安装包提供，推理在本机完成。AgPlayer不将本地歌曲、录音、音乐库及处理数据用于广告跟踪、用户画像或远程训练，不上报本地播放、音频处理统计或崩溃日志。支持作者功能的华为SDK会处理支付接口调用和交易记录，具体说明见第七节。

二、权限用途

文件访问仅用于导入、扫描、编辑及保存您选择的内容；持久文件授权用于重启后继续访问已授权的内容。麦克风权限仅在您主动使用音频编辑录音时请求，拒绝授权不影响普通播放。后台媒体服务和播放通知在您主动播放时用于持续播放及系统播控；来电或通知暂时中断时保持服务，待系统归还音频焦点后按中断前状态恢复。网络访问及网络状态权限用于同意本政策后的华为联运初始化、公告及官方版本检查，以及主动打开支持作者后的华为商品查询、收银台和订单恢复。撤回文件授权可能使相关歌曲无法继续打开，但不会删除原始文件。
音频工具保存时，您可选择另存副本，或明确授权覆盖原文件。覆盖只在输出格式与目标一致、获得写入授权并完成本地恢复备份后执行；写入失败会尝试恢复原文件。恢复失败时保留本地备份并提示其位置；请先完成恢复，再清理缓存。不同格式的处理结果须另存副本。

华为官方更新组件声明应用安装更新权限，用于您在华为更新界面确认后的更新安装；不用于静默安装。华为应用市场服务地查询权限由官方组件用于确定对应的市场服务区域。

仅在您点击“扫描手机歌曲”时，本应用请求系统音频读取权限（Android 13 及以上）或适用的存储读取权限（Android 8–12），用于读取系统媒体库中可访问的本地音频。扫描结果可多选导入，扫描可随时停止，不会自动在后台扫描。拒绝扫描权限后，仍可通过系统文件选择器或授权文件夹导入歌曲。本应用不申请所有文件访问权限；在安卓兼容环境中，扫描范围由该环境开放的存储决定。

三、保存与清理

您可在 Android 系统设置中管理权限和应用缓存。清理本应用数据或卸载不会删除华为保存的支付订单；交易信息的管理及相关请求请通过华为帐号、支付服务或华为客服处理。仅清理缓存不会删除原始音频或已保存到其他目录的结果；清除应用数据会删除本应用私有目录中的音乐库索引、设置及未另行导出的处理结果。模型副本可从安装包离线恢复。卸载应用后，保存在其他目录的文件可能仍留在设备上。系统文件选择器或其他文件提供方展示内容的方式由相应系统或应用决定，本应用自身不连接其网络服务。

四、您的权利与联系

本应用没有用户账户，因此无需注销。您可在本机管理文件授权、清理缓存或清除应用数据。开发者为吴国志，客服及隐私联系邮箱为 agplayer@foxmail.com；您可以就应用使用、支持作者付款、订单恢复及本地数据处理提出问题或请求。“设置 → 关于 AgPlayer”和“支持作者”页面均提供邮箱、发送邮件及复制邮箱入口。应用不会自动发送邮件；您主动通过其他应用发送邮件时，由相应邮件服务处理邮件地址及所提供的内容。
首次启动会展示本政策，由您选择同意或不同意；同意前不读取音乐库、音频、录音或恢复播放。您可在“设置 → 关于 AgPlayer → 隐私政策”撤回同意并停止播放，或进入系统权限管理撤回权限。撤回同意不会删除原始文件。

五、未成年人及政策更新

未成年人请在监护人指导下使用。如将来增加联网或新的个人信息处理功能，我们会在实施前更新政策并按适用要求取得必要授权。本政策可在应用内离线阅读。

六、本地组件说明

FFmpeg、LAME、Opus 和 SoundTouch 用于本地音频解码、编码与音调处理，ONNX Runtime 用于本地伴奏分离模型推理，AndroidX 用于界面与系统交互。这些组件不在本应用中收集或发送设备标识、位置、音频、联系人、使用统计或其他信息，不包含广告或统计服务。相关开源许可随安装包提供。

七、支持作者与华为应用内支付SDK

支持作者完全自愿，不解锁功能，不影响本地播放、编辑或处理，也不是自动续费订阅。只有您主动打开“设置 → 关于 AgPlayer → 支持作者”，并已同意本渠道隐私政策后，AgPlayer才初始化及调用华为应用内支付SDK。商品名称和价格由华为应用市场返回，您须在华为收银台确认付款，也可取消。

第三方SDK名称：华为应用内支付SDK（HMS Core IAP）。提供方：华为软件技术有限公司。用途：查询支持商品、拉起华为收银台、核对支付结果及确认或恢复未消费订单。根据华为SDK隐私声明，SDK会直接收集调用SDK接口的信息并上传服务器，用于完成支付，处理的个人信息包括交易记录。华为应用内支付服务由华为独立提供，具体账户、付款及交易数据处理请阅读收银台及华为服务的隐私说明。

AgPlayer在支持页存活期间处理华为返回的商品、金额、币种、订单号、购买令牌及签名，用于验签、消费确认和避免重复确认；这些订单数据不写入本应用的持久存储，不上传开发者服务器。支持页再次打开时会向华为查询并恢复已付款但尚未完成确认的支持订单。签名或确认失败时会提示恢复订单，不把失败显示成支持成功。本应用不读取银行卡资料、支付密码，也不把本地音频、录音、音乐库或工程发送给华为。华为SDK及服务的独立交易数据处理不属于第六节所述的离线组件。

八、华为应用市场联运与更新服务

第三方SDK名称：华为联运应用SDK（AppGalleryKit App / HMS Core appservice）、更新组件及初始化所需的华为帐号SDK（Account Kit / hwid）。提供方：华为软件技术有限公司。用途：按华为应用市场联运要求，在您同意当前政策并进入首个稳定主界面后，完成应用初始化、应用公告及官方版本检查；有新版本时通过华为官方更新界面提示和处理，由您在相应界面确认。AgPlayer不因此主动调用帐号登录接口或增加帐号系统。

该SDK直接连接华为服务，处理提供联运及更新服务所需的应用信息（包括包名、版本、签名）、设备及系统信息、网络信息和接口调用信息；请求所需的IP地址等网络信息会由华为接收。具体处理范围以华为SDK及服务的隐私声明为准。该SDK不在同意前由本应用主动初始化或调用。AgPlayer不向该SDK传入本地音频、录音、歌单、播放记录或音频工程，也不因此增加开发者自己的统计或用户账户系统。无网络或检查失败不影响本地音乐功能。
