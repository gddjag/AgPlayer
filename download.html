常见问题与简易教程

使用教程

怎么把音乐加入曲库？

在桌面版曲库的侧栏点「添加资源文件夹」，选中存放音乐的文件夹。歌曲出现后，可以打星评分、加入收藏，再按评分或标签筛选。播放与整理都在本机完成，无需注册账号。

网页试听怎样切换波形和跳播？

在「波形试听室」点「添加本地音乐」，选一首歌后按播放。点四种波形名称可切换显示，点波形中的位置可跳到相应时间。若浏览器无法读取文件，可在桌面版中打开。

怎样拖出歌曲中的一小段？

在桌面版单窗口模式中打开歌曲，在底部的整曲波形上框选需要的范围。把选区拖到桌面，即可得到该片段，也可直接拖到支持接收文件的剪辑软件时间线。

怎样剪掉片段并制作淡出？

在桌面版「音频工具」打开「音频编辑」，点击「导入音频」。将播放头移到剪切点，按 S 分割，再拖动片段边缘裁剪。在音量线上双击添加两个控制点，把后一个向下拖，试听后点「导出音频」。

怎样单独导出人声或伴奏？

在「音频工具」打开分离工具，点「选择文件」，选好模型后点「开始分离」。处理完成后先试听，再点「导出人声」或「导出伴奏」并选择目录。鼓、贝斯等其他音轨取决于所选模型。

安装与注意事项

Windows 和 Mac 应该选哪个安装包？

Windows 可在「设置 → 系统 → 关于」查看系统类型。Intel 或 AMD 的 64 位电脑选 x64，基于 ARM 的 Windows 电脑选 ARM64。Mac 在苹果菜单的「关于本机」查看芯片，M 系列选 Apple，Intel 处理器选 Intel。

需要离线分离，应该选哪个版本？

官网 Windows 和 macOS 可以选「内置伴奏分离模型版本」，安装后即可离线分离。使用常规纯净版时，先在「音频工具」里联网下载所需模型。Android 和原生鸿蒙版已内置模型。

Edge 提示「通常不会下载」，怎么办？

官网 Windows 包暂未使用受信任的代码签名证书。如果只是下载信誉提示，请先确认文件来自本页官网链接或官方 GitHub 镜像，再从下载项菜单选择「保留」。打开前核对该安装包的 SHA-256。如明确报出恶意软件，请停止运行。

macOS 首次打开时出现安全提示，怎么办？

此版本尚未经过 Apple 公证。先核对下载来源和所选安装包的 SHA-256，再查看下载卡片中的 Apple 官方教程，按提示处理。校验值不同请重新下载。

安卓和鸿蒙在哪里安装？

64 位 Android 8.0 及以上设备可从本页下载 Android APK。要安装原生鸿蒙 PC 或手机版，请到鸿蒙应用市场搜索 AgPlayer。使用华为卓易通时，也可以选择安卓版本。
